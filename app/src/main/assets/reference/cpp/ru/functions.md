# Функции

**Функция** — именованный блок кода с параметрами и результатом. Её объявляют один раз и вызывают сколько угодно.

## Объявление и вызов

```cpp
#include <iostream>
using namespace std;

double average(int a, int b, int c)
{
    return (a + b + c) / 3.0;
}

void printLine(int width)
{
    for (int i = 0; i < width; i++) cout << '-';
    cout << '\n';
}

int main()
{
    printLine(20);
    cout << "Средний балл: " << average(8, 9, 7) << '\n';
    printLine(20);
}
```

```output
--------------------
Средний балл: 8
--------------------
```

Сначала тип результата (`void` — ничего не возвращает), затем имя и параметры.

## Прототип

Функцию нужно объявить **до** места вызова. Если тело удобнее написать после `main`, сверху ставят **прототип** — объявление без тела:

```cpp
int square(int x);          // прототип

int main()
{
    cout << square(5);      // 25
}

int square(int x)
{
    return x * x;
}
```

В больших проектах прототипы выносят в заголовочный файл `.h`, а реализацию — в `.cpp`.

## Передача по значению и по ссылке

По умолчанию функция получает **копию** аргумента. Знак `&` у параметра делает его **ссылкой** — функция работает с исходной переменной:

```cpp
void addOne(int n)   { n++; }
void addOneRef(int& n) { n++; }

int x = 5;
addOne(x);      // x = 5
addOneRef(x);   // x = 6
```

Обмен значений:

```cpp
void swapValues(int& a, int& b)
{
    int t = a;
    a = b;
    b = t;
}
```

Большие объекты (строки, векторы) передают по **константной ссылке** — без копирования и без права менять:

```cpp
void printName(const string& name)
{
    cout << name << '\n';
}
```

## Параметры по умолчанию

```cpp
void greet(const string& name, const string& text = "Привет")
{
    cout << text << ", " << name << "!\n";
}

greet("Анна");                  // Привет, Анна!
greet("Олег", "Добрый день");   // Добрый день, Олег!
```

Параметры по умолчанию пишут в конце списка и указывают только в прототипе (если он есть).

## Перегрузка

Можно объявить несколько функций с одним именем и разными параметрами:

```cpp
int maxOf(int a, int b) { return a > b ? a : b; }
double maxOf(double a, double b) { return a > b ? a : b; }
int maxOf(int a, int b, int c) { return maxOf(maxOf(a, b), c); }
```

## Рекурсия

Функция может вызывать сама себя. Обязателен базовый случай:

```cpp
long long factorial(int n)
{
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

cout << factorial(10); // 3628800
```

> [!WARNING]
> Если функция с типом результата не дойдёт до `return`, поведение не определено: программа может вернуть мусор. Компилятор обычно предупреждает об этом — не игнорируйте предупреждения.

## Проверь себя

> [!QUIZ]
> Зачем нужен прототип функции?
> ---
> Чтобы вызвать функцию раньше, чем написано её тело: компилятор должен знать сигнатуру до вызова.

> [!QUIZ]
> Чем `void f(int& x)` отличается от `void f(int x)`?
> ---
> С `&` функция получает ссылку и может изменить исходную переменную, без `&` — работает с копией.
