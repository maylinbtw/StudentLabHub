# Переменные и типы данных

Переменная в C++ — именованная область памяти определённого типа. Тип задаётся при объявлении и потом не меняется.

## Объявление и инициализация

```cpp
int count;              // объявление: значение не определено!
int labs = 12;          // инициализация через =
double avg(7.5);        // через круглые скобки
int marks{9};           // универсальная инициализация (C++11)
int a = 1, b = 2;       // несколько переменных
```

> [!WARNING]
> Локальная переменная без инициализации содержит «мусор» — случайное значение из памяти. Компилятор это не запрещает. Всегда задавайте начальное значение.

Фигурные скобки строже: `int x{3.7};` — ошибка, а `int x = 3.7;` молча отбросит дробную часть.

## Основные типы

| Тип | Размер (обычно) | Что хранит |
|---|---|---|
| `bool` | 1 байт | `true` или `false` |
| `char` | 1 байт | символ или маленькое число |
| `short` | 2 байта | целое ±32 767 |
| `int` | 4 байта | целое ±2,1 млрд |
| `long long` | 8 байт | целое ±9,2·10¹⁸ |
| `float` | 4 байта | дробное, ~7 цифр |
| `double` | 8 байт | дробное, ~15 цифр |

Модификатор `unsigned` делает тип неотрицательным и удваивает верхнюю границу: `unsigned int` — от 0 до ~4,3 млрд. Точный размер типа на вашей системе покажет `sizeof(int)`.

## Строки и символы

```cpp
#include <string>

char grade = 'A';                 // один символ — одинарные кавычки
std::string name = "Анна";        // строка — двойные кавычки
std::string full = name + " К.";  // склейка строк
int len = name.length();          // длина в байтах
```

> `std::string` хранит байты, а не буквы. Русская буква в UTF-8 занимает 2 байта, поэтому `length()` для "Анна" вернёт 8.

## auto

`auto` выводит тип из значения:

```cpp
auto x = 10;        // int
auto pi = 3.14;     // double
auto c = 'z';       // char
auto s = std::string("text");
```

## Константы

```cpp
const int MaxLabs = 20;           // нельзя изменить после инициализации
constexpr double Pi = 3.14159;    // вычисляется при компиляции
```

## Область видимости

```cpp
int global = 1;          // глобальная — видна во всём файле

int main()
{
    int local = 2;       // локальная — до конца main
    {
        int inner = 3;   // видна только в этом блоке
    }
    // inner здесь недоступна
    return 0;
}
```

Глобальные переменные инициализируются нулём автоматически, локальные — нет.

## Приведение типов

```cpp
double d = 7.9;
int i = static_cast<int>(d);      // 7 — явное приведение
double r = static_cast<double>(7) / 2;   // 3.5
int old = (int)d;                  // приведение в стиле C, лучше избегать
```

## Проверь себя

> [!QUIZ]
> Какое значение у локальной переменной `int x;` без инициализации?
> ---
> Неопределённое — там может быть любой мусор. Чтение такой переменной — неопределённое поведение.

> [!QUIZ]
> Что делает `auto` в `auto n = 10;`?
> ---
> Компилятор сам выводит тип по значению — здесь `int`.
