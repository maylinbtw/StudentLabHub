# Консольный ввод и вывод

Для работы с консолью используется класс `Console`. Он умеет выводить текст, читать строки и отдельные клавиши.

## Вывод: Write и WriteLine

`Console.WriteLine` выводит значение и переводит строку, `Console.Write` — без перевода:

```csharp
Console.Write("Лабораторная ");
Console.Write(5);
Console.WriteLine();          // пустая строка = просто перевод строки
Console.WriteLine("сдана");
```

```output
Лабораторная 5
сдана
```

## Интерполяция строк

Самый удобный способ собрать строку из значений — **интерполяция**. Перед кавычками ставится `$`, а выражения пишутся в фигурных скобках:

```csharp
string name = "Иван";
int done = 7, total = 10;

Console.WriteLine($"{name} сдал {done} из {total} работ");
Console.WriteLine($"Осталось: {total - done}");
```

```output
Иван сдал 7 из 10 работ
Осталось: 3
```

Старые способы, которые встречаются в учебниках:

```csharp
Console.WriteLine(name + " сдал " + done + " работ");     // конкатенация
Console.WriteLine("{0} сдал {1} работ", name, done);       // составное форматирование
```

## Форматирование чисел

После двоеточия внутри `{ }` указывается формат:

| Формат | Значение | Результат |
|---|---|---|
| `{x:F2}` | 3.14159 | 3,14 |
| `{x:N0}` | 1234567 | 1 234 567 |
| `{x:P1}` | 0.256 | 25,6 % |
| `{x:C}` | 99.5 | 99,50 ₽ |
| `{x,5}` | 42 | `   42` (ширина 5) |
| `{x:D3}` | 7 | 007 |

```csharp
double avg = 4.3333;
Console.WriteLine($"Средний балл: {avg:F1}");
```

```output
Средний балл: 4,3
```

> Разделитель дробной части и символ валюты зависят от языка системы: в русской локали выводится запятая, в английской — точка.

## Ввод: ReadLine

`Console.ReadLine()` ждёт, пока пользователь введёт строку и нажмёт Enter, и возвращает её как `string?`. Если ввод закончился (например, перенаправлен пустой файл), вернётся `null`.

```csharp
Console.Write("Введите группу: ");
string? group = Console.ReadLine();
Console.WriteLine($"Группа: {group}");
```

## Ввод чисел

`ReadLine` всегда возвращает строку. Чтобы получить число, строку нужно **преобразовать**:

```csharp
Console.Write("Возраст: ");
int age = int.Parse(Console.ReadLine()!);

Console.Write("Рост в метрах: ");
double height = double.Parse(Console.ReadLine()!);

Console.WriteLine($"Через год вам будет {age + 1}");
```

Знак `!` сообщает компилятору, что мы уверены: `null` здесь не будет.

> [!WARNING]
> Если ввести не число (например, «двадцать»), `int.Parse` выбросит исключение `FormatException`, и программа завершится с ошибкой. Безопасный способ — `int.TryParse`.

```csharp
Console.Write("Количество работ: ");
if (int.TryParse(Console.ReadLine(), out int count))
{
    Console.WriteLine($"Принято: {count}");
}
else
{
    Console.WriteLine("Это не целое число");
}
```

`TryParse` возвращает `true`, если преобразование удалось, а результат кладёт в переменную после `out`.

## Чтение клавиши

`Console.ReadKey()` ждёт нажатия одной клавиши. Часто его ставят в конце программы, чтобы окно консоли не закрывалось сразу:

```csharp
Console.WriteLine("Нажмите любую клавишу...");
Console.ReadKey();
```

## Кириллица в консоли

Если вместо русских букв выводятся знаки вопроса, задайте кодировку в начале программы:

```csharp
Console.OutputEncoding = System.Text.Encoding.UTF8;
Console.InputEncoding = System.Text.Encoding.UTF8;
```
