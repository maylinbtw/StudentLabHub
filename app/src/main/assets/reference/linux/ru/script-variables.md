# Переменные и вычисления в bash

## Переменные

```bash
name="Анна"
lab=3
echo "Студент: $name, лаба $lab"
echo "Файл: ${name}_lab${lab}.txt"   # фигурные скобки — граница имени
```

```output
Студент: Анна, лаба 3
Файл: Анна_lab3.txt
```

> [!WARNING]
> При присваивании не ставьте пробелы вокруг `=`: `lab = 3` — ошибка `lab: command not found`.

## Кавычки

```bash
name="Анна"
echo "Привет, $name"    # двойные — переменные подставляются: Привет, Анна
echo 'Привет, $name'    # одинарные — текст как есть: Привет, $name
```

Всегда берите переменные в двойные кавычки: `"$file"`. Иначе имя с пробелами (`мои лабы.txt`) разобьётся на два аргумента.

## Подстановка команд

```bash
today=$(date +%Y-%m-%d)
files=$(ls | wc -l)
echo "Сегодня $today, файлов в папке: $files"
```

## Арифметика

bash считает только целые числа:

```bash
a=7
b=3
echo $((a + b))     # 10
echo $((a * b))     # 21
echo $((a / b))     # 2 — целочисленное деление
echo $((a % b))     # 1 — остаток

count=0
((count++))
((count += 5))
echo $count         # 6
```

Для дробных чисел используют `bc`:

```bash
echo "scale=2; 17 / 3" | bc     # 5.66
```

## Операции со строками

```bash
file="report_lab3.docx"

echo ${#file}            # 16 — длина
echo ${file%.docx}       # report_lab3 — убрать с конца
echo ${file#report_}     # lab3.docx — убрать с начала
echo ${file/lab3/lab4}   # report_lab4.docx — замена
echo ${file:0:6}         # report — подстрока
echo ${file^^}           # REPORT_LAB3.DOCX — в верхний регистр
```

Значение по умолчанию:

```bash
dir=${1:-.}              # первый аргумент или «.», если не передан
echo "Обрабатываю папку $dir"
```

## Массивы

```bash
subjects=("Математика" "Физика" "ОАиП")

echo ${subjects[0]}          # Математика
echo ${#subjects[@]}         # 3 — количество
subjects+=("БД")             # добавить

for s in "${subjects[@]}"; do
    echo "- $s"
done
```

## Специальные переменные

| Переменная | Значение |
|---|---|
| `$0` | имя скрипта |
| `$1`…`$9` | аргументы |
| `$#` | число аргументов |
| `$@` | все аргументы списком |
| `$?` | код завершения последней команды |
| `$$` | PID текущего скрипта |
| `$RANDOM` | случайное число 0–32767 |

## Константы и локальность

```bash
readonly MAX_LABS=10
# MAX_LABS=5 — ошибка: переменная только для чтения
```

Переменные в скрипте по умолчанию **глобальные** и не видны программам, которые он запускает, пока их не сделать `export`.
