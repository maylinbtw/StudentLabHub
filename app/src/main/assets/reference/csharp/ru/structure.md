# Структура программы

Программа на C# состоит из **инструкций**, которые объединяются в **блоки**, методы и классы.

## Инструкции

Инструкция — одно действие: объявить переменную, вызвать метод, присвоить значение. Каждая простая инструкция заканчивается точкой с запятой:

```csharp
int a = 5;
a = a + 1;
Console.WriteLine(a);
```

Можно записать несколько инструкций в одну строку, но читать такой код тяжелее:

```csharp
int a = 5; a = a + 1; Console.WriteLine(a);
```

## Блоки кода

Фигурные скобки `{ }` объединяют инструкции в блок. Блоки используются в методах, классах, условиях и циклах:

```csharp
if (a > 5)
{
    Console.WriteLine("Больше пяти");
    Console.WriteLine("Блок из двух инструкций");
}
```

Переменная, объявленная внутри блока, видна только в нём.

## Регистр символов

C# различает заглавные и строчные буквы. `Console`, `console` и `CONSOLE` — три разных имени, и правильное из них только первое:

```csharp
console.WriteLine("Ошибка"); // CS0103: имя console не существует
```

## Комментарии

Комментарии компилятор пропускает. Они нужны, чтобы пояснить код:

```csharp
// Однострочный комментарий — до конца строки

/*
   Многострочный комментарий.
   Удобно временно отключить кусок кода.
*/

/// <summary>
/// XML-комментарий: описание метода для подсказок IDE.
/// </summary>
```

## Пространства имён и using

Классы .NET разложены по **пространствам имён**. Например, `Console` находится в `System`, а `List<T>` — в `System.Collections.Generic`. Директива `using` позволяет не писать полное имя:

```csharp
using System.Text;

var builder = new StringBuilder(); // вместо System.Text.StringBuilder
```

> В новых проектах включены **неявные using**: самые нужные пространства имён (`System`, `System.IO`, `System.Linq` и др.) подключаются автоматически. Поэтому в шаблоне нет строки `using System;`.

## Соглашения об именах

| Что | Стиль | Пример |
|---|---|---|
| Классы, методы, свойства | PascalCase | `StudentList`, `GetAverage` |
| Локальные переменные, параметры | camelCase | `studentName`, `count` |
| Константы | PascalCase | `MaxScore` |
| Закрытые поля | _camelCase | `_items` |

Компилятор не требует этих правил, но так оформлен код .NET и большинство проектов.
