# Условия в bash: if, test, case

## if

```bash
#!/bin/bash
read -p "Оценка: " mark

if [ "$mark" -ge 9 ]; then
    echo "Отлично"
elif [ "$mark" -ge 4 ]; then
    echo "Сдано"
else
    echo "Не сдано"
fi
```

> [!WARNING]
> Внутри `[ ]` обязательны пробелы: `[ "$a" -eq 1 ]`. Запись `["$a" -eq 1]` — ошибка `command not found`.

## Сравнение чисел

| Оператор | Значение |
|---|---|
| `-eq` | равно |
| `-ne` | не равно |
| `-lt` / `-le` | меньше / меньше или равно |
| `-gt` / `-ge` | больше / больше или равно |

В двойных круглых скобках можно писать привычные знаки:

```bash
if (( mark >= 4 && mark <= 10 )); then
    echo "Оценка в диапазоне"
fi
```

## Сравнение строк

| Запись | Значение |
|---|---|
| `[ "$a" = "$b" ]` | строки равны |
| `[ "$a" != "$b" ]` | не равны |
| `[ -z "$a" ]` | строка пустая |
| `[ -n "$a" ]` | строка не пустая |

```bash
if [ -z "$1" ]; then
    echo "Использование: $0 <имя файла>"
    exit 1
fi
```

## Проверка файлов

| Запись | Истинно, если |
|---|---|
| `-e путь` | существует |
| `-f путь` | это обычный файл |
| `-d путь` | это папка |
| `-r` / `-w` / `-x` | можно читать / писать / запускать |
| `-s путь` | файл не пустой |

```bash
if [ -d "build" ]; then
    echo "Папка build уже есть"
else
    mkdir build
fi

[ -f config.txt ] || echo "Нет config.txt"
```

## Логические операции

```bash
if [ -f "$file" ] && [ -r "$file" ]; then
    cat "$file"
fi

if [[ "$ext" == "cpp" || "$ext" == "c" ]]; then
    echo "Исходник C/C++"
fi
```

`[[ ]]` — расширенная проверка bash: внутри работают `&&`, `||`, шаблоны и регулярные выражения:

```bash
if [[ "$file" == *.txt ]]; then
    echo "Текстовый файл"
fi

if [[ "$group" =~ ^П-[0-9]{2}$ ]]; then
    echo "Номер группы корректный"
fi
```

## Проверка результата команды

`if` проверяет код завершения команды — `[ ]` тоже просто команда:

```bash
if grep -q "TODO" main.py; then
    echo "В коде остались TODO"
fi

if ping -c 1 -W 1 8.8.8.8 > /dev/null; then
    echo "Интернет есть"
fi
```

## case

Удобен, когда одно значение сравнивается с несколькими вариантами:

```bash
#!/bin/bash
case "$1" in
    build)
        echo "Сборка..."
        ;;
    run|start)
        echo "Запуск..."
        ;;
    *.zip)
        echo "Распаковка $1"
        unzip "$1"
        ;;
    *)
        echo "Использование: $0 {build|run|архив.zip}"
        exit 1
        ;;
esac
```

- каждый вариант заканчивается `;;`;
- `|` — несколько вариантов в одной ветке;
- `*` — всё остальное, как `default`.
