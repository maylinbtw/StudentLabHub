# Строки

Строка (`str`) — неизменяемая последовательность символов. Её можно записать в одинарных, двойных или тройных кавычках.

```python
a = 'Привет'
b = "Привет"
c = """Многострочный
текст"""
path = r"C:\labs\new"      # r — «сырая» строка, \ не экранирует
```

## Индексы и срезы

Работают так же, как у списков:

```python
s = "Python"
s[0]       # 'P'
s[-1]      # 'n'
s[0:3]     # 'Pyt'
s[::-1]    # 'nohtyP'
len(s)     # 6
```

Изменить символ нельзя: `s[0] = "J"` вызовет `TypeError`. Создайте новую строку: `"J" + s[1:]`.

## Основные методы

```python
s = "  Лабораторная работа  "

s.strip()                # 'Лабораторная работа' — убрать пробелы по краям
s.lower(), s.upper()     # регистр
s.strip().title()        # 'Лабораторная Работа'
s.replace("работа", "№3")
s.find("работа")         # индекс или -1
s.count("а")             # сколько раз встречается
s.startswith("  Лаб")    # True
"42".isdigit()           # True
"abc".isalpha()          # True
```

Методы не меняют строку, а возвращают новую — результат нужно сохранить: `s = s.strip()`.

## Разбиение и склеивание

```python
line = "Анна;П-21;8.4"
name, group, avg = line.split(";")
print(group)                         # П-21

words = "мама мыла раму".split()     # по пробелам: ['мама', 'мыла', 'раму']

print(", ".join(["C#", "Java", "Python"]))   # C#, Java, Python
print("-".join("abc"))                        # a-b-c
```

> [!WARNING]
> `join` принимает только строки. Для чисел сначала преобразуйте: `" ".join(map(str, [1, 2, 3]))`.

## f-строки

```python
name = "Анна"
avg = 8.456

print(f"{name}: {avg:.2f}")       # Анна: 8.46
print(f"{name:>10}|")             # выравнивание вправо на 10
print(f"{name:<10}|")             # влево
print(f"{42:05d}")                # 00042
print(f"{0.256:.1%}")             # 25.6%
print(f"{1234567:,}")             # 1,234,567
print(f"{avg=}")                  # avg=8.456 — для отладки
```

## Проверка вхождения

```python
"лаб" in "лабораторная"         # True
"Лаб" in "лабораторная"         # False — регистр важен
```

## Перебор символов

```python
vowels = 0
for ch in "программирование":
    if ch in "аеёиоуыэюя":
        vowels += 1
print(vowels)   # 7
```

## Многострочный текст и спецсимволы

| Запись | Значение |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\\` | обратный слэш |
| `\"` | кавычка внутри строки |

```python
print("Строка 1\nСтрока 2")
print("Имя\tОценка")
```

## Коды символов

```python
ord("A")      # 65
chr(66)       # 'B'
```

## Проверь себя

> [!QUIZ]
> Меняет ли `s.upper()` саму строку `s`?
> ---
> Нет: строки неизменяемы, метод возвращает новую строку. Нужно `s = s.upper()`.

> [!QUIZ]
> Как склеить список `[1, 2, 3]` в строку "1 2 3"?
> ---
> `" ".join(map(str, [1, 2, 3]))` — `join` принимает только строки.
