# Ввод и вывод

Консольный ввод-вывод в C++ работает через **потоки** из библиотеки `<iostream>`: `cout` — вывод, `cin` — ввод, `cerr` — вывод ошибок.

## Вывод: cout

Оператор `<<` можно ставить подряд — значения выводятся одно за другим:

```cpp
#include <iostream>
using namespace std;

int main()
{
    int done = 7, total = 10;
    cout << "Сделано " << done << " из " << total << endl;
    cout << "Вторая строка\n";
    return 0;
}
```

```output
Сделано 7 из 10
Вторая строка
```

`endl` переводит строку и сбрасывает буфер вывода, `'\n'` только переводит строку и работает быстрее.

## Ввод: cin

Оператор `>>` читает значение и записывает его в переменную. Пробелы и переводы строк между значениями пропускаются:

```cpp
int age;
double height;

cout << "Возраст и рост: ";
cin >> age >> height;
cout << "Через год вам будет " << age + 1 << endl;
```

```output
Возраст и рост: 19 1.82
Через год вам будет 20
```

## Чтение строки целиком

`cin >> s` читает только одно слово — до первого пробела. Для строки целиком есть `getline`:

```cpp
#include <string>

string fullName;
cout << "ФИО: ";
getline(cin, fullName);
```

> [!WARNING]
> Если перед `getline` был `cin >> ...`, в буфере остаётся символ перевода строки, и `getline` сразу вернёт пустую строку. Пропустите его: `cin.ignore();` перед `getline`.

## Проверка ввода

Если пользователь ввёл буквы вместо числа, поток переходит в состояние ошибки:

```cpp
int n;
cout << "Введите число: ";

while (!(cin >> n))
{
    cout << "Это не число, ещё раз: ";
    cin.clear();                  // сбросить ошибку
    cin.ignore(10000, '\n');      // выбросить неверный ввод
}
```

## Форматирование: iomanip

```cpp
#include <iomanip>

double avg = 7.4567;
cout << fixed << setprecision(2) << avg << endl;      // 7.46
cout << setw(6) << 42 << '|' << endl;                  // "    42|"
cout << left << setw(10) << "Имя" << "Балл" << endl;  // выравнивание влево
cout << right << setfill('0') << setw(3) << 7 << endl; // 007
```

| Манипулятор | Действие |
|---|---|
| `fixed` | запись с фиксированной точкой |
| `setprecision(n)` | n знаков после точки (вместе с `fixed`) |
| `setw(n)` | ширина следующего значения |
| `left` / `right` | выравнивание |
| `setfill(c)` | символ заполнения |
| `boolalpha` | выводить `true`/`false` вместо 1/0 |

## printf и scanf

В учебниках встречается ввод-вывод в стиле C из `<cstdio>`:

```cpp
#include <cstdio>

int n = 5;
double x = 2.5;
printf("n = %d, x = %.2f\n", n, x);
scanf("%d", &n);
```

Основные спецификаторы: `%d` — int, `%f` — double в printf, `%lf` — double в scanf, `%c` — char, `%s` — строка C.
