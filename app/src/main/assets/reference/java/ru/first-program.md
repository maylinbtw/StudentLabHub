# Первая программа на Java

**Java** — объектно-ориентированный язык, программы на котором работают на **виртуальной машине JVM**. Компилятор переводит код в байт-код, а JVM выполняет его на любой ОС. На Java пишут серверы, корпоративные системы и Android-приложения.

## Что нужно установить

- **JDK** (Java Development Kit) — компилятор `javac`, JVM и стандартная библиотека. Подойдёт любая актуальная LTS-версия, например 21;
- среда разработки: IntelliJ IDEA, Eclipse или VS Code с расширением для Java.

```bash
java -version
javac -version
```

## Код программы

Создайте файл `Main.java`:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

- весь код в Java находится внутри **классов**. Здесь класс называется `Main`;
- `public static void main(String[] args)` — **точка входа**, с неё начинается выполнение;
- `System.out.println` выводит строку и переводит курсор на новую строку;
- каждая инструкция заканчивается `;`.

> [!WARNING]
> Имя публичного класса должно совпадать с именем файла, включая регистр: класс `Main` — файл `Main.java`. Иначе компилятор выдаст ошибку.

## Компиляция и запуск

```bash
javac Main.java      # создаёт байт-код Main.class
java Main            # запускает класс Main (без .class)
```

```output
Hello, World!
```

Начиная с Java 11, однофайловую программу можно запустить без отдельной компиляции:

```bash
java Main.java
```

## Пакеты

В реальных проектах классы раскладывают по **пакетам** — это папки с особыми именами:

```java
package com.slh.labs;

public class Lab1 {
    public static void main(String[] args) {
        System.out.println("Лабораторная 1");
    }
}
```

Файл должен лежать в `com/slh/labs/Lab1.java`. IntelliJ IDEA создаёт папки сама.

## Соглашения об именах

| Что | Стиль | Пример |
|---|---|---|
| Классы | PascalCase | `StudentList` |
| Методы и переменные | camelCase | `getAverage`, `labCount` |
| Константы | UPPER_SNAKE_CASE | `MAX_LABS` |
| Пакеты | строчные | `com.slh.labs` |

## Проверь себя

> [!QUIZ]
> Как должен называться файл с классом `public class Main`?
> ---
> `Main.java` — имя публичного класса и файла должны совпадать.

> [!QUIZ]
> Что делает JVM?
> ---
> Выполняет байт-код, в который `javac` компилирует программу, поэтому один и тот же код работает на разных ОС.
