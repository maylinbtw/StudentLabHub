# Поиск и обработка текста

Сила Linux — в маленьких командах, которые соединяются в цепочки. Каждая делает одно действие с текстом, а **конвейер** `|` передаёт результат следующей.

## Перенаправление вывода

```bash
ls -l > list.txt             # записать вывод в файл (файл перезаписывается)
echo "lab3" >> done.txt      # дописать в конец файла
sort < names.txt             # взять ввод из файла
gcc main.c 2> errors.txt     # ошибки (поток 2) — в отдельный файл
make > build.log 2>&1        # и вывод, и ошибки в один файл
cmd > /dev/null              # выбросить вывод
```

У каждой программы три потока: `0` — ввод (stdin), `1` — вывод (stdout), `2` — ошибки (stderr).

## Конвейеры

`|` передаёт вывод одной команды на вход другой:

```bash
ls -l /etc | less                    # листать длинный список
ps aux | grep java                   # найти процессы java
cat access.log | wc -l               # сколько строк в логе
history | tail -n 20                 # последние 20 команд
```

## grep — поиск строк

```bash
grep "error" app.log                 # строки, где есть error
grep -i "error" app.log              # без учёта регистра
grep -n "TODO" main.c                # с номерами строк
grep -r "main(" src/                 # во всех файлах папки
grep -v "^#" config.ini              # строки, которые НЕ начинаются с #
grep -c "GET" access.log             # только количество совпадений
grep -E "lab[0-9]+" list.txt         # расширенные регулярные выражения
```

Самые нужные элементы регулярных выражений: `^` — начало строки, `$` — конец, `.` — любой символ, `*` — повтор предыдущего 0 и более раз, `[0-9]` — любая цифра.

## wc, sort, uniq

```bash
wc -l main.c                         # строки
wc -w essay.txt                      # слова
sort names.txt                       # по алфавиту
sort -n numbers.txt                  # как числа
sort -r -k2 marks.txt                # по второму столбцу в обратном порядке
sort names.txt | uniq                # убрать повторы
sort names.txt | uniq -c | sort -rn  # частота каждой строки, самые частые сверху
```

> `uniq` убирает только **соседние** повторы, поэтому перед ним почти всегда ставят `sort`.

## cut и tr

```bash
cut -d ':' -f 1 /etc/passwd          # первый столбец, разделитель «:»
cut -d ',' -f 2,4 data.csv           # 2-й и 4-й столбцы CSV
echo "Hello" | tr 'a-z' 'A-Z'        # заменить символы: HELLO
tr -d '\r' < win.txt > unix.txt      # убрать символы \r из файла Windows
```

## sed — замена в потоке

```bash
sed 's/old/new/' file.txt            # первое совпадение в каждой строке
sed 's/old/new/g' file.txt           # все совпадения
sed -i 's/8080/9090/g' config.ini    # изменить сам файл
sed -n '10,20p' log.txt              # вывести строки с 10 по 20
sed '/^$/d' file.txt                 # удалить пустые строки
```

## awk — работа со столбцами

`awk` делит каждую строку на поля: `$1`, `$2`… (`$0` — вся строка).

```bash
awk '{print $1}' access.log                  # первый столбец
awk -F ',' '{print $2, $3}' data.csv         # CSV: 2-й и 3-й столбцы
awk '$3 > 8 {print $1}' marks.txt            # фамилии, у кого оценка больше 8
awk '{sum += $2} END {print sum / NR}' marks.txt   # среднее по второму столбцу
```

## Пример цепочки

Десять IP-адресов, которые чаще всего обращались к серверу:

```bash
cut -d ' ' -f 1 access.log | sort | uniq -c | sort -rn | head -n 10
```

```output
    412 192.168.1.15
    208 192.168.1.40
     97 10.0.0.7
```

## Сравнение файлов

```bash
diff old.c new.c                     # отличия построчно
diff -u old.c new.c                  # в формате патча (как в git)
```

## Проверь себя

> [!QUIZ]
> Чем `>` отличается от `>>`?
> ---
> `>` перезаписывает файл, `>>` дописывает в конец.

> [!QUIZ]
> Как посчитать строки, где встречается слово `error`?
> ---
> `grep -c error log.txt` или `grep error log.txt | wc -l`.
