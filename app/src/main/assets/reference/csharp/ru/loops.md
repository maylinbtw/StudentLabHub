# Циклы

Цикл повторяет блок кода, пока выполняется условие. В C# четыре вида циклов: `for`, `while`, `do…while` и `foreach`. Последний разобран в статье про массивы.

## Цикл for

`for` удобен, когда заранее известно число повторений:

```text
for (инициализация; условие; шаг)
{
    тело цикла
}
```

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.Write($"{i} ");
}
```

```output
1 2 3 4 5 
```

Порядок работы:

1. Один раз выполняется инициализация: `int i = 1`.
2. Проверяется условие `i <= 5`. Если оно ложно, цикл завершается.
3. Выполняется тело цикла.
4. Выполняется шаг `i++`, и всё повторяется с пункта 2.

Шаг может быть любым: `i += 2`, `i--`, `i *= 2`.

```csharp
for (int i = 10; i > 0; i -= 3)
    Console.Write($"{i} ");   // 10 7 4 1
```

## Цикл while

`while` проверяет условие **перед** каждым повтором. Если условие сразу ложно, тело не выполнится ни разу:

```csharp
int left = 3;

while (left > 0)
{
    Console.WriteLine($"Осталось работ: {left}");
    left--;
}
```

```output
Осталось работ: 3
Осталось работ: 2
Осталось работ: 1
```

`while` подходит, когда число повторений заранее неизвестно, например при чтении ввода до команды выхода.

## Цикл do…while

`do…while` проверяет условие **после** тела, поэтому тело выполнится хотя бы один раз:

```csharp
int number;

do
{
    Console.Write("Введите число от 1 до 10: ");
}
while (!int.TryParse(Console.ReadLine(), out number) || number < 1 || number > 10);

Console.WriteLine($"Принято: {number}");
```

Это типичный способ повторять запрос, пока пользователь не введёт корректное значение.

> Обратите внимание на точку с запятой после `while (…)` в конце `do…while` — без неё будет ошибка.

## break и continue

- `break` немедленно завершает цикл;
- `continue` пропускает остаток текущего повтора и переходит к следующему.

```csharp
for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
        continue;       // чётные пропускаем
    if (i > 7)
        break;          // после 7 выходим
    Console.Write($"{i} ");
}
```

```output
1 3 5 7 
```

## Вложенные циклы

Цикл может находиться внутри другого. Внутренний цикл полностью проходит на каждом шаге внешнего:

```csharp
for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= 3; col++)
    {
        Console.Write($"{row * col,4}");
    }
    Console.WriteLine();
}
```

```output
   1   2   3
   2   4   6
   3   6   9
```

`break` во вложенном цикле завершает только внутренний цикл.

## Бесконечный цикл

Если условие никогда не становится ложным, цикл не закончится. Иногда это делают намеренно и выходят через `break`:

```csharp
while (true)
{
    Console.Write("> ");
    string? input = Console.ReadLine();
    if (input == "exit")
        break;
    Console.WriteLine($"Вы ввели: {input}");
}
```

> [!WARNING]
> Если программа «зависла», проверьте, меняется ли в цикле переменная из условия. Забытый `i++` — самая частая причина бесконечного цикла.

## Проверь себя

> [!QUIZ]
> Сколько раз выполнится тело `do { } while (false);`?
> ---
> Один раз: `do…while` проверяет условие после тела.

> [!QUIZ]
> Чем `break` отличается от `continue`?
> ---
> `break` полностью выходит из цикла, `continue` переходит к следующей итерации.
