# Терминал и командная строка

**Терминал** — программа, в которой вы вводите команды текстом. Команды выполняет **оболочка** (shell). В большинстве дистрибутивов это `bash`, в некоторых — `zsh`.

## Приглашение

Когда оболочка готова принять команду, она показывает **приглашение**:

```text
student@pc:~/labs$
```

- `student` — имя пользователя;
- `pc` — имя компьютера;
- `~/labs` — текущая папка (`~` означает домашнюю папку);
- `$` — обычный пользователь, `#` — администратор (root).

> В примерах справочника приглашение не пишется: копируйте только саму команду.

## Синтаксис команды

```text
команда [параметры] [аргументы]
```

```bash
ls -l -a /etc
ls -la /etc        # короткие параметры можно объединять
ls --all /etc      # длинная форма параметра
```

- **команда** — имя программы: `ls`, `cp`, `grep`;
- **параметры** (ключи) меняют поведение: короткие начинаются с `-`, длинные — с `--`;
- **аргументы** — то, с чем работает команда: файлы, папки, текст.

Регистр важен: `ls` и `LS` — разные команды, `-a` и `-A` — разные параметры.

## Справка по командам

```bash
ls --help          # краткая справка прямо в терминале
man ls             # полное руководство (выход — клавиша q)
type cd            # что это: встроенная команда, программа или псевдоним
```

> Если команды нет в этом справочнике, найдите её через поиск: краткую справку можно скачать из tldr-pages, и она будет доступна без интернета.

## Полезные клавиши

| Клавиши | Действие |
|---|---|
| `Tab` | дополнить имя команды или файла |
| `Tab Tab` | показать все варианты дополнения |
| `↑` / `↓` | листать историю команд |
| `Ctrl+C` | прервать выполняющуюся команду |
| `Ctrl+L` | очистить экран (то же, что `clear`) |
| `Ctrl+R` | поиск по истории |
| `Ctrl+D` | выйти из оболочки |

`Tab` — главный помощник: он экономит время и защищает от опечаток в путях.

## История команд

```bash
history            # список последних команд с номерами
!42                # повторить команду номер 42
!!                 # повторить последнюю команду
sudo !!            # повторить последнюю команду с правами администратора
```

## Несколько команд в одной строке

```bash
mkdir lab1 ; cd lab1          # выполнить по очереди
make && ./app                 # вторую — только если первая успешна
ping -c1 host || echo "нет связи"   # вторую — только если первая с ошибкой
```

Каждая команда возвращает **код завершения**: `0` — успех, любое другое число — ошибка. Узнать код последней команды можно через `echo $?`.

## Проверь себя

> [!QUIZ]
> Как быстро найти команду, которую вводили раньше?
> ---
> `Ctrl+R` и начать печатать — поиск по истории. Ещё есть `history` и стрелка вверх.

> [!QUIZ]
> Чем `cmd1 && cmd2` отличается от `cmd1; cmd2`?
> ---
> С `&&` вторая команда выполнится, только если первая успешна. С `;` — в любом случае.
