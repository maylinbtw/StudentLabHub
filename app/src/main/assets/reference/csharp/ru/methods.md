# Методы

**Метод** — именованный блок кода, который выполняет одну задачу. Его можно вызвать из разных мест программы, вместо того чтобы копировать один и тот же код.

## Объявление метода

```csharp
static void SayHello()
{
    Console.WriteLine("Привет!");
}
```

Из чего состоит объявление:

| Часть | Значение |
|---|---|
| `static` | метод принадлежит классу, объект создавать не нужно |
| `void` | тип результата; `void` — метод ничего не возвращает |
| `SayHello` | имя метода, принято писать с большой буквы (PascalCase) |
| `()` | список параметров, здесь пустой |
| `{ }` | тело метода |

## Вызов метода

Чтобы выполнить метод, пишут его имя и скобки:

```csharp
SayHello();
SayHello();
```

```output
Привет!
Привет!
```

> [!NOTE]
> В программе с верхнеуровневыми инструкциями (без `Main`) методы можно объявлять прямо в файле `Program.cs` — после основного кода. Внутри класса их пишут рядом с `Main`.

## Параметры

**Параметры** — входные данные метода. Они перечисляются в скобках с типами, а при вызове передаются **аргументы**:

```csharp
static void PrintMark(string subject, int mark)
{
    Console.WriteLine($"{subject}: {mark}");
}

PrintMark("Математика", 9);
PrintMark("Физика", 7);
```

```output
Математика: 9
Физика: 7
```

Аргументы должны совпадать с параметрами по количеству, порядку и типу.

## Возврат значения: return

Если метод должен вычислить результат, вместо `void` указывают тип, а значение возвращают через `return`:

```csharp
static double Average(int a, int b, int c)
{
    return (a + b + c) / 3.0;
}

double avg = Average(8, 9, 7);
Console.WriteLine(avg); // 8
```

`return` сразу завершает метод. В методе с типом результата каждый путь выполнения должен заканчиваться `return`:

```csharp
static string Grade(int mark)
{
    if (mark >= 9) return "отлично";
    if (mark >= 6) return "хорошо";
    if (mark >= 4) return "удовлетворительно";
    return "не сдано";
}
```

> [!WARNING]
> Если убрать последний `return`, будет ошибка CS0161: не все пути к коду возвращают значение.

В `void`-методе `return;` без значения используют, чтобы выйти раньше:

```csharp
static void PrintPositive(int n)
{
    if (n <= 0) return;
    Console.WriteLine(n);
}
```

## Методы-выражения

Если тело метода — одно выражение, его можно записать через `=>`:

```csharp
static int Square(int x) => x * x;
static bool IsEven(int n) => n % 2 == 0;
static void Line() => Console.WriteLine(new string('-', 20));
```

## Локальные переменные

Переменные, объявленные внутри метода, видны только в нём. Два метода могут иметь переменные с одинаковыми именами — они не мешают друг другу:

```csharp
static int Sum(int[] items)
{
    int total = 0;
    foreach (int item in items) total += item;
    return total;
}
```

`total` существует только во время работы `Sum` и исчезает после выхода из метода.
