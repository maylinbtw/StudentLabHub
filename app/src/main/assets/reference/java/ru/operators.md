# Операции

Арифметические, логические операции и операции сравнения в Java работают так же, как в C и C#, но с важными отличиями: `boolean` нельзя заменить числом, а строки сравнивают через `equals`.

## Арифметика

| Операция | Пример | Результат |
|---|---|---|
| `+` `-` `*` | `7 * 2` | 14 |
| `/` | `7 / 2` | 3 — у целых дробная часть отбрасывается |
| `/` | `7.0 / 2` | 3.5 |
| `%` | `-7 % 3` | -1 — знак как у делимого |

```java
int sum = 25, count = 4;
double avg = (double) sum / count;   // 6.25
int pages = (total + 9) / 10;        // деление с округлением вверх
```

Деление целого на `0` выбрасывает `ArithmeticException`. Деление `double` на `0` даёт `Infinity` или `NaN`.

## Инкремент и составное присваивание

```java
int x = 5;
int a = x++;   // a = 5, x = 6
int b = ++x;   // b = 7, x = 7

x += 10;
x -= 2;
x *= 3;

byte small = 10;
small += 5;           // можно: += приводит тип сам
// small = small + 5; — ошибка: результат int
```

## Сравнение и логика

```java
int mark = 8;
boolean good = mark >= 7 && mark <= 10;
boolean retake = mark < 4 || absent;
boolean notGood = !good;
```

- `&&` и `||` — с сокращённым вычислением;
- `&` и `|` с `boolean` вычисляют обе части;
- `if (1)` не скомпилируется — нужен именно `boolean`.

## Класс Math

```java
Math.pow(2, 10);       // 1024.0
Math.sqrt(81);         // 9.0
Math.abs(-7);          // 7
Math.max(3, 8);        // 8
Math.round(2.5);       // 3 — к ближайшему, половина вверх
Math.floor(2.9);       // 2.0
Math.ceil(2.1);        // 3.0
Math.random();         // случайное число от 0.0 до 1.0 (не включая 1)
```

Случайное целое от 1 до 10:

```java
int dice = (int) (Math.random() * 10) + 1;
// или
int r = new java.util.Random().nextInt(1, 11);   // Java 17+
```

## Переполнение

```java
int big = Integer.MAX_VALUE;   // 2147483647
big++;                          // -2147483648 — «перескок» без ошибки
int safe = Math.addExact(Integer.MAX_VALUE, 1);   // ArithmeticException
```

Для больших значений берите `long`, для произвольно больших — `BigInteger`, для денег — `BigDecimal`.

## Тернарная операция

```java
String status = mark >= 4 ? "зачтено" : "незачтено";
int max = a > b ? a : b;
```

## Проверь себя

> [!QUIZ]
> Чему равно `10 / 4` и `10 / 4.0`?
> ---
> `2` и `2.5`: деление целых отбрасывает дробную часть.

> [!QUIZ]
> Что будет при `Integer.MAX_VALUE + 1`?
> ---
> Переполнение без ошибки: получится `Integer.MIN_VALUE`. Для проверки есть `Math.addExact`.
