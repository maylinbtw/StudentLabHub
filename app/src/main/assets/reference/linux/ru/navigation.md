# Файловая система и навигация

В Linux нет дисков `C:` и `D:`. Все файлы находятся в одном дереве, которое начинается с **корня** `/`. Флешки и другие диски подключаются (монтируются) в папки этого дерева.

## Основные каталоги

| Каталог | Что там |
|---|---|
| `/` | корень файловой системы |
| `/home` | домашние папки пользователей (`/home/student`) |
| `/root` | домашняя папка администратора |
| `/etc` | файлы настроек системы и программ |
| `/bin`, `/usr/bin` | программы (команды) |
| `/var/log` | журналы (логи) системы |
| `/tmp` | временные файлы, очищаются при перезагрузке |
| `/dev` | файлы устройств: диски, терминалы |
| `/mnt`, `/media` | точки подключения дисков и флешек |

## Абсолютные и относительные пути

- **абсолютный** путь начинается с `/` и указывает место от корня: `/home/student/labs/lab1.c`;
- **относительный** путь отсчитывается от текущей папки: `labs/lab1.c`.

Специальные обозначения:

| Запись | Значение |
|---|---|
| `~` | домашняя папка текущего пользователя |
| `.` | текущая папка |
| `..` | родительская папка (на уровень выше) |
| `-` | предыдущая папка (для `cd`) |

> Имена файлов чувствительны к регистру: `Lab.txt` и `lab.txt` — два разных файла. Пробелы в именах приходится экранировать: `cd "My Labs"` или `cd My\ Labs`.

## pwd — где я

```bash
pwd
```

```output
/home/student/labs
```

## cd — перейти в папку

```bash
cd /var/log        # по абсолютному пути
cd labs/lab2       # по относительному пути
cd ..              # на уровень выше
cd ../..           # на два уровня выше
cd ~               # домой (то же, что просто cd)
cd -               # вернуться в предыдущую папку
```

## ls — содержимое папки

```bash
ls                 # имена файлов и папок
ls -l              # подробный список: права, владелец, размер, дата
ls -a              # показать скрытые файлы (их имена начинаются с точки)
ls -lh             # размеры в удобном виде: 4,0K, 12M
ls -lt             # отсортировать по времени изменения
ls -R              # рекурсивно, со всеми вложенными папками
ls /etc            # содержимое другой папки, не переходя в неё
```

Пример вывода `ls -lh`:

```output
drwxr-xr-x 2 student student 4,0K окт 27 10:12 lab1
-rw-r--r-- 1 student student  12K окт 27 11:05 report.odt
```

Первый символ строки: `d` — папка, `-` — обычный файл, `l` — ссылка. Остальные символы — права доступа, о них в отдельной статье.

## tree — дерево каталогов

```bash
tree -L 2          # структура на два уровня вглубь
```

Если команды нет, установите её: `sudo apt install tree` (Debian, Ubuntu).

## Сколько места занято

```bash
df -h              # свободное место на дисках
du -sh labs        # сколько занимает папка labs
du -sh *           # размер каждого элемента в текущей папке
```

## Проверь себя

> [!QUIZ]
> Куда ведёт `cd ~` и `cd -`?
> ---
> `cd ~` — в домашнюю папку, `cd -` — в предыдущую папку.

> [!QUIZ]
> Как показать скрытые файлы?
> ---
> `ls -a`: скрытыми считаются файлы, имя которых начинается с точки.
