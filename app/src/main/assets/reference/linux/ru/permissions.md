# Права доступа

У каждого файла в Linux есть **владелец**, **группа** и набор **прав**: кто может читать, изменять и запускать файл.

## Как читать права

```bash
ls -l script.sh
```

```output
-rwxr-xr-- 1 student students 312 окт 27 14:02 script.sh
```

Строка `rwxr-xr--` состоит из трёх троек:

| Тройка | Для кого | Здесь |
|---|---|---|
| `rwx` | владелец (user, `u`) | чтение, запись, запуск |
| `r-x` | группа (group, `g`) | чтение и запуск |
| `r--` | остальные (others, `o`) | только чтение |

Буквы означают:

| Буква | Для файла | Для папки |
|---|---|---|
| `r` | читать содержимое | смотреть список файлов |
| `w` | изменять | создавать и удалять файлы внутри |
| `x` | запускать как программу | заходить в папку (`cd`) |

## chmod — изменить права

**Символьная** запись: кому (`u`, `g`, `o`, `a` — все), что сделать (`+`, `-`, `=`), какие права:

```bash
chmod +x script.sh           # разрешить запуск всем
chmod u+x script.sh          # только владельцу
chmod go-w report.txt        # запретить запись группе и остальным
chmod a=r notes.txt          # всем только чтение
chmod -R g+w project/        # рекурсивно для папки
```

**Числовая** запись: каждая тройка — сумма чисел `r = 4`, `w = 2`, `x = 1`:

| Число | Права | Типичное применение |
|---|---|---|
| `755` | `rwxr-xr-x` | программы, скрипты, папки |
| `644` | `rw-r--r--` | обычные файлы |
| `700` | `rwx------` | личная папка |
| `600` | `rw-------` | секретные файлы, ключи SSH |

```bash
chmod 755 deploy.sh
chmod 600 ~/.ssh/id_ed25519
```

> [!WARNING]
> Не используйте `chmod 777` «чтобы заработало»: так любой пользователь системы сможет изменить или удалить файл.

## Запуск своего скрипта

```bash
nano hello.sh                # создать скрипт
chmod +x hello.sh            # разрешить запуск
./hello.sh                   # запустить из текущей папки
```

`./` обязательно: оболочка ищет команды только в папках из переменной `PATH`, а текущей папки там нет.

## Владелец и группа

```bash
chown student report.txt             # сменить владельца
chown student:students report.txt    # владельца и группу
chown -R www-data /var/www/site      # рекурсивно
chgrp students shared/               # только группу
```

Менять владельца может только администратор, поэтому эти команды обычно запускают через `sudo`.

## sudo — права администратора

```bash
sudo apt update              # выполнить одну команду от имени root
sudo -i                      # открыть оболочку администратора (выход — exit)
whoami                       # под каким пользователем вы работаете
id                           # ваш UID, группы
groups                       # в каких группах вы состоите
```

`sudo` спросит **ваш** пароль, а не пароль root. При вводе пароля символы не отображаются — это нормально.

## Пользователи и группы

```bash
sudo adduser ivan                    # создать пользователя
sudo usermod -aG students ivan       # добавить в группу students
passwd                               # сменить свой пароль
su - ivan                            # войти под другим пользователем
```
