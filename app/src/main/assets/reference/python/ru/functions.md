# Функции

**Функция** — именованный блок кода, который можно вызывать много раз. Объявляется словом `def`.

## Объявление и вызов

```python
def average(a, b, c):
    return (a + b + c) / 3

def print_line(width):
    print("-" * width)

print_line(20)
print("Средний балл:", average(8, 9, 7))
print_line(20)
```

```output
--------------------
Средний балл: 8.0
--------------------
```

- тело функции выделяется отступом;
- `return` возвращает значение и завершает функцию;
- функция без `return` возвращает `None`;
- функцию нужно объявить раньше, чем она будет вызвана.

## Несколько результатов

Функция может вернуть несколько значений — на самом деле это кортеж, который удобно распаковать:

```python
def min_max(items):
    return min(items), max(items)

lo, hi = min_max([4, 9, 2, 7])
print(lo, hi)   # 2 9
```

## Параметры по умолчанию и именованные аргументы

```python
def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")

greet("Анна")                      # Привет, Анна!
greet("Олег", "Добрый день")       # Добрый день, Олег!
greet(greeting="Хай", name="Ира")  # по именам — порядок не важен
```

> [!WARNING]
> Не используйте изменяемые значения по умолчанию: `def add(x, items=[])`. Список создаётся **один раз** при объявлении функции и копит значения между вызовами. Правильно: `items=None`, а внутри `if items is None: items = []`.

## *args и **kwargs

```python
def total(*numbers):          # любое число позиционных аргументов → кортеж
    return sum(numbers)

print(total(1, 2, 3))         # 6

def show(**info):             # любое число именованных → словарь
    for key, value in info.items():
        print(f"{key}: {value}")

show(name="Анна", group="П-21")
```

## Аннотации типов

Типы можно указать для читаемости и подсказок редактора. На выполнение они не влияют:

```python
def grade(mark: int) -> str:
    if mark >= 9:
        return "отлично"
    if mark >= 4:
        return "сдано"
    return "не сдано"
```

## Область видимости

Переменные, созданные внутри функции, — **локальные**. Чтобы изменить глобальную переменную, нужно `global`:

```python
counter = 0

def increment():
    global counter
    counter += 1

increment()
print(counter)  # 1
```

Лучше не злоупотреблять `global`: передавайте значения параметрами и возвращайте результат.

## lambda

Короткая безымянная функция в одно выражение:

```python
square = lambda x: x * x
print(square(5))   # 25

students = [("Анна", 8.4), ("Олег", 6.1), ("Ира", 9.2)]
students.sort(key=lambda s: s[1], reverse=True)
print(students[0][0])   # Ира
```

## Строка документации

Первая строка в теле функции в тройных кавычках — **docstring**. Её показывает `help()` и подсказки редактора:

```python
def average(marks):
    """Возвращает средний балл списка оценок."""
    return sum(marks) / len(marks)
```

## Рекурсия

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(10))   # 3628800
```

> [!NOTE]
> По умолчанию глубина рекурсии ограничена примерно 1000 вызовами — дальше `RecursionError`. Для глубоких задач лучше цикл.
