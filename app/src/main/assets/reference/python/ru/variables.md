# Переменные и типы данных

В Python тип переменной не объявляется: он определяется значением, которое в неё записано. Одна и та же переменная может хранить сначала число, а потом строку — это **динамическая типизация**.

## Переменные

```python
labs = 12               # int
avg = 7.5               # float
name = "Анна"           # str
passed = True           # bool
nothing = None          # «нет значения»

a, b = 1, 2             # несколько переменных сразу
a, b = b, a             # обмен значениями без временной переменной
x = y = 0               # одно значение двум переменным
```

Имена пишут в стиле `snake_case`: `lab_count`, `average_mark`. Константы — заглавными: `MAX_LABS = 20` (это соглашение, Python не запрещает их менять).

## Основные типы

| Тип | Пример | Описание |
|---|---|---|
| `int` | `42`, `-7`, `1_000_000` | целые, без ограничения размера |
| `float` | `3.14`, `1e-3` | дробные (double) |
| `str` | `"текст"`, `'текст'` | строки, неизменяемые |
| `bool` | `True`, `False` | логический тип (с большой буквы) |
| `NoneType` | `None` | отсутствие значения |
| `list` | `[1, 2, 3]` | список, изменяемый |
| `tuple` | `(1, 2)` | кортеж, неизменяемый |
| `dict` | `{"ЛР1": 9}` | словарь «ключ → значение» |
| `set` | `{1, 2, 3}` | множество без повторов |

```python
print(type(avg))           # <class 'float'>
print(isinstance(labs, int))   # True
```

> Целые числа в Python не переполняются: `2 ** 100` спокойно вычислится в огромное точное число.

## Строки

```python
name = "Анна"
print(len(name))           # 4 — длина в символах
print(name[0])             # А
print(name[-1])            # а — последний символ
print(name.upper())        # АННА
print(name * 2)            # АннаАнна
print("Ан" in name)        # True
```

## Преобразование типов

```python
n = int("42")              # строка → целое
x = float("3.5")           # строка → дробное
s = str(42)                # число → строка
i = int(7.9)               # 7 — дробная часть отбрасывается
b = bool(0)                # False; пустые строки и списки тоже False
```

> [!WARNING]
> `int("3.5")` и `int("abc")` выбрасывают `ValueError`. Сложение `"5" + 5` выбрасывает `TypeError`: Python не превращает строки в числа сам.

## Ссылки на объекты

Переменная в Python — это имя, привязанное к объекту. При присваивании копируется ссылка:

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)                   # [1, 2, 3, 4] — это один и тот же список

c = a.copy()               # независимая копия
```

Для неизменяемых типов (`int`, `str`, `tuple`) это незаметно: любое «изменение» создаёт новый объект.
