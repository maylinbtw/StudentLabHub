# Преобразования типов

Значение одного типа часто нужно превратить в другой: целое — в дробное, строку — в число, число — в строку. В C# есть несколько способов, и важно понимать, какой из них может потерять данные.

## Неявные преобразования

Если преобразование **безопасно** (данные не теряются), компилятор делает его сам:

```csharp
int count = 42;
long big = count;       // int → long
double real = count;    // int → double
float f = 'A';          // char → float (код символа 65)
```

Безопасная цепочка для чисел: `byte` → `short` → `int` → `long` → `float` → `double`. Преобразования в `decimal` из целых типов тоже неявные.

## Явные преобразования (приведение)

Если данные могут потеряться, компилятор требует явного **приведения** — тип в скобках перед значением:

```csharp
double price = 9.99;
int whole = (int)price;      // 9 — дробная часть отброшена, без округления

long big = 3_000_000_000;
int overflow = (int)big;     // -1294967296 — значение не поместилось
```

> [!WARNING]
> При приведении числа к меньшему типу «лишние» биты просто отрезаются, и программа продолжает работать с неверным значением без всякой ошибки.

## checked: ловим переполнение

Внутри блока или выражения `checked` переполнение выбрасывает `OverflowException` вместо тихой ошибки:

```csharp
long big = 3_000_000_000;
try
{
    int value = checked((int)big);
}
catch (OverflowException)
{
    Console.WriteLine("Число не помещается в int");
}
```

```output
Число не помещается в int
```

## Строка → число

| Способ | Если строка некорректна |
|---|---|
| `int.Parse(s)` | исключение `FormatException` |
| `int.TryParse(s, out int n)` | возвращает `false`, `n = 0` |
| `Convert.ToInt32(s)` | исключение; для `null` возвращает 0 |

```csharp
int a = int.Parse("125");
double b = double.Parse("3,5");          // в русской локали — запятая

if (int.TryParse("12a", out int c))
    Console.WriteLine(c);
else
    Console.WriteLine("Не число");
```

```output
Не число
```

> Разделитель дробной части зависит от языка системы. Чтобы всегда читать числа с точкой, используйте `double.Parse("3.5", CultureInfo.InvariantCulture)` (пространство имён `System.Globalization`).

## Число → строка

У каждого значения есть метод `ToString()`. В него можно передать формат:

```csharp
int n = 7;
double avg = 4.567;

string s1 = n.ToString();          // "7"
string s2 = avg.ToString("F1");    // "4,6"
string s3 = n.ToString("D3");      // "007"
string s4 = $"{avg:F2}";           // "4,57" — то же через интерполяцию
```

## Класс Convert

`Convert` умеет переводить между базовыми типами. В отличие от приведения, при переводе дробного в целое он **округляет** (по банковскому правилу):

```csharp
Console.WriteLine((int)2.7);              // 2
Console.WriteLine(Convert.ToInt32(2.7));  // 3
Console.WriteLine(Convert.ToInt32(2.5));  // 2 — к ближайшему чётному
Console.WriteLine(Convert.ToBoolean(1));  // True
Console.WriteLine(Convert.ToString(255, 2)); // 11111111 — в двоичной системе
```

## Итог

- Без потерь — неявно, ничего писать не нужно.
- С возможной потерей — `(тип)значение`, а при риске переполнения — `checked`.
- Пользовательский ввод — `TryParse`, чтобы программа не падала.
- Число в текст — интерполяция или `ToString("формат")`.

## Проверь себя

> [!QUIZ]
> Чем `int.Parse` отличается от `int.TryParse`?
> ---
> `Parse` выбрасывает исключение при неверной строке, `TryParse` возвращает `false` и не падает.

> [!QUIZ]
> Что получится при `(int)3.99`?
> ---
> 3 — явное приведение к `int` отбрасывает дробную часть без округления.
