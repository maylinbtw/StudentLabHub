# Язык C# и платформа .NET

**C#** (читается «си шарп») — объектно-ориентированный язык общего назначения от Microsoft. На нём пишут настольные и веб-приложения, серверы, мобильные приложения, игры на Unity и утилиты для командной строки.

## Что такое .NET

Программа на C# не запускается сама по себе: ей нужна платформа **.NET**. В неё входят:

- **компилятор** — переводит исходный код `.cs` в промежуточный язык IL;
- **среда выполнения CLR** — загружает IL и во время работы превращает его в машинный код (JIT-компиляция);
- **библиотека классов** — готовые типы для строк, файлов, коллекций, сети и многого другого;
- **SDK и утилита `dotnet`** — создание, сборка и запуск проектов.

Благодаря промежуточному языку одна и та же сборка работает на Windows, Linux и macOS, если там установлена среда .NET.

## Как программа превращается в результат

1. Вы пишете код в файлах `.cs`.
2. Команда `dotnet build` компилирует их в сборку `.dll` с кодом IL.
3. Команда `dotnet run` (или запуск готового файла) передаёт сборку среде CLR.
4. CLR компилирует нужные методы в машинный код и выполняет их.

> Сборщик мусора (GC) в CLR сам освобождает память, которая больше не используется. Вручную вызывать `delete`, как в C++, не нужно.

## Версии

Язык и платформа развиваются вместе: каждая новая версия .NET приносит новую версию C#. Примеры в этом справочнике рассчитаны на современный .NET (8 и новее) и стиль программ без явного метода `Main`. Если в колледже стоит старая версия Visual Studio, часть синтаксиса может не поддерживаться — это отмечено в статьях.

## Что понадобится

| Инструмент | Для чего |
|---|---|
| .NET SDK | Компилятор и утилита `dotnet` |
| Visual Studio | Полноценная IDE для Windows |
| VS Code + C# Dev Kit | Лёгкий редактор для любой ОС |
| JetBrains Rider | IDE для Windows, Linux и macOS |

Проверить, что SDK установлен, можно в терминале:

```bash
dotnet --version
```

```output
8.0.404
```

Номер версии у вас может отличаться — главное, чтобы команда не выдавала ошибку.

## Проверь себя

> [!QUIZ]
> Во что компилятор C# превращает исходный код?
> ---
> В промежуточный язык **IL**. При запуске среда .NET (CLR) переводит его в машинный код с помощью JIT-компиляции.

> [!QUIZ]
> Чем .NET отличается от C#?
> ---
> C# — язык программирования, а .NET — платформа: среда выполнения и библиотеки, на которых работает программа.
