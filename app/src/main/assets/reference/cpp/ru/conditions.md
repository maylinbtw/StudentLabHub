# Условия: if и switch

Условные конструкции выбирают, какой код выполнить, в зависимости от значения выражения.

## if, else if, else

```cpp
int mark;
cin >> mark;

if (mark >= 9)
{
    cout << "Отлично\n";
}
else if (mark >= 4)
{
    cout << "Зачтено\n";
}
else
{
    cout << "Пересдача\n";
}
```

Условия проверяются сверху вниз, выполняется первая подходящая ветка.

> Если ветка состоит из одной инструкции, скобки можно не писать. Но `else` всегда относится к ближайшему `if` без пары, поэтому во вложенных условиях скобки лучше ставить.

## if с инициализацией (C++17)

Переменную можно объявить прямо в условии — она будет видна только внутри `if` и `else`:

```cpp
if (int left = total - done; left > 0)
{
    cout << "Осталось " << left << '\n';
}
```

## Тернарная операция

```cpp
int mark = 5;
string status = mark >= 4 ? "зачтено" : "незачтено";
cout << "Максимум: " << (a > b ? a : b) << '\n';
```

## switch

`switch` сравнивает целое значение (или `char`, `enum`) с константами:

```cpp
char op;
double a, b;
cin >> a >> op >> b;

switch (op)
{
    case '+':
        cout << a + b << '\n';
        break;
    case '-':
        cout << a - b << '\n';
        break;
    case '*':
        cout << a * b << '\n';
        break;
    case '/':
        if (b != 0)
            cout << a / b << '\n';
        else
            cout << "Деление на ноль\n";
        break;
    default:
        cout << "Неизвестная операция\n";
}
```

```output
6 * 7
42
```

> [!WARNING]
> Без `break` выполнение **проваливается** в следующий `case`. Иногда это делают намеренно (несколько значений — одно действие), но чаще это ошибка. Если провал задуман, отметьте его атрибутом `[[fallthrough]];`.

```cpp
switch (day)
{
    case 6:
    case 7:
        cout << "Выходной\n";
        break;
    default:
        cout << "Учёба\n";
}
```

## Ограничения switch

- нельзя проверять строки `std::string` — используйте цепочку `if`;
- нельзя проверять диапазоны вроде `case 1..5`;
- объявлять переменную внутри `case` можно только в фигурных скобках:

```cpp
case 1:
{
    int temp = 10;
    cout << temp;
    break;
}
```
