# Условия: if и match

## if, elif, else

```python
mark = int(input("Оценка: "))

if mark >= 9:
    print("Отлично")
elif mark >= 4:
    print("Зачтено")
else:
    print("Пересдача")
```

- после условия ставится двоеточие `:`;
- тело ветки выделяется отступом;
- вместо `else if` пишется `elif`;
- скобки вокруг условия не нужны.

> [!WARNING]
> Пустая ветка недопустима. Если код ещё не написан, поставьте `pass` — инструкцию, которая ничего не делает.

```python
if mark < 4:
    pass   # обработку пересдачи добавлю позже
```

## Вложенные условия

```python
if done:
    if defended:
        print("Работа закрыта")
    else:
        print("Нужно защитить")
else:
    print("Нужно сделать")
```

## Условное выражение

Аналог тернарной операции записывается словами:

```python
status = "зачтено" if mark >= 4 else "незачтено"
print(f"Максимум: {a if a > b else b}")
```

## Проверка вхождения

`in` проверяет, есть ли значение в строке, списке, словаре или множестве:

```python
day = input("День: ").lower()

if day in ("суббота", "воскресенье"):
    print("Выходной")

if "ЛР" in title:
    print("Это лабораторная")
```

## match (Python 3.10+)

`match` сравнивает значение с **образцами** — это более мощный аналог `switch`:

```python
command = input("> ").strip().lower()

match command:
    case "add":
        print("Добавляем работу")
    case "list" | "ls":
        print("Список работ")
    case "exit" | "quit":
        print("Выход")
    case _:
        print("Неизвестная команда")
```

- `|` объединяет несколько вариантов;
- `_` — «всё остальное», аналог `default`;
- проваливания между ветками нет, `break` не нужен.

## Образцы с условиями и распаковкой

```python
match mark:
    case 10:
        print("Идеально")
    case m if m >= 7:
        print(f"Хорошо: {m}")
    case _:
        print("Можно лучше")
```

`match` умеет разбирать списки и кортежи:

```python
parts = input("> ").split()

match parts:
    case ["add", name]:
        print(f"Добавить {name}")
    case ["rename", old, new]:
        print(f"{old} → {new}")
    case []:
        print("Пустая команда")
    case _:
        print("Не понял")
```
