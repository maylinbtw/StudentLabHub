# Указатели и динамическая память

**Указатель** — переменная, которая хранит **адрес** другой переменной в памяти.

## Адрес и разыменование

```cpp
int mark = 8;
int* p = &mark;      // & — взять адрес

cout << p << '\n';   // адрес, например 0x7ffd5c3a
cout << *p << '\n';  // 8 — * читает значение по адресу

*p = 10;             // меняем mark через указатель
cout << mark;        // 10
```

| Запись | Значение |
|---|---|
| `int* p` | объявление указателя на `int` |
| `&x` | адрес переменной `x` |
| `*p` | значение по адресу `p` |
| `p->field` | поле объекта по указателю, то же что `(*p).field` |

## nullptr

Указатель, который никуда не указывает, равен `nullptr`:

```cpp
int* p = nullptr;
if (p != nullptr)
    cout << *p;
```

> [!WARNING]
> Разыменование `nullptr` или неинициализированного указателя — неопределённое поведение, обычно падение программы. Инициализируйте указатели сразу.

## Указатели и массивы

Имя массива превращается в указатель на первый элемент. К указателю можно прибавлять число:

```cpp
int a[] = {10, 20, 30};
int* p = a;

cout << *p << '\n';        // 10
cout << *(p + 2) << '\n';  // 30 — то же, что a[2]
```

## Указатель или ссылка

| | Указатель `int*` | Ссылка `int&` |
|---|---|---|
| может быть пустым | да, `nullptr` | нет |
| можно перенаправить | да | нет, привязана навсегда |
| синтаксис доступа | `*p`, `p->x` | как у обычной переменной |

Если нужно просто изменить аргумент функции — используйте ссылку. Указатель — когда значение может отсутствовать или нужна динамическая память.

## new и delete

Память, выделенная через `new`, живёт, пока её явно не освободят через `delete`:

```cpp
int* n = new int(5);
cout << *n << '\n';
delete n;

int size;
cin >> size;
int* arr = new int[size];   // массив размера из ввода
for (int i = 0; i < size; i++) arr[i] = i * i;
delete[] arr;               // для массивов — delete[]
```

> [!WARNING]
> Забыли `delete` — **утечка памяти**. Вызвали `delete` дважды или обратились к памяти после `delete` — неопределённое поведение. Поэтому в современном C++ голые `new`/`delete` почти не пишут.

## Умные указатели

Из `<memory>` — указатели, которые сами освобождают память:

```cpp
#include <memory>

unique_ptr<int> a = make_unique<int>(42);
cout << *a << '\n';           // 42
// delete не нужен — память освободится при выходе из области видимости

shared_ptr<string> s1 = make_shared<string>("общая");
shared_ptr<string> s2 = s1;   // оба владеют, счётчик = 2
```

- `unique_ptr` — единственный владелец, копировать нельзя (только `move`);
- `shared_ptr` — несколько владельцев, память освобождается, когда уходит последний.

Вместо динамического массива почти всегда лучше `vector`.
