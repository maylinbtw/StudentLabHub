# Первый скрипт bash

**Скрипт** — текстовый файл с командами, которые оболочка выполняет по порядку. Всё, что вы делаете в терминале руками, можно записать в скрипт и запускать одной командой.

## Создание и запуск

```bash
nano hello.sh
```

```bash
#!/bin/bash
# Мой первый скрипт
echo "Привет, $USER!"
echo "Сегодня $(date +%d.%m.%Y)"
echo "Ты в папке: $(pwd)"
```

```bash
chmod +x hello.sh     # разрешить запуск
./hello.sh            # запустить
```

```output
Привет, student!
Сегодня 29.10.2026
Ты в папке: /home/student
```

- первая строка `#!/bin/bash` — **шебанг**: указывает, какой программой выполнять файл;
- `#` в начале строки — комментарий;
- `$(команда)` подставляет вывод команды.

Без `chmod +x` скрипт можно запустить так: `bash hello.sh`.

## Аргументы скрипта

```bash
#!/bin/bash
echo "Имя скрипта: $0"
echo "Первый аргумент: $1"
echo "Второй аргумент: $2"
echo "Всего аргументов: $#"
echo "Все аргументы: $@"
```

```bash
./args.sh лаба3 срочно
```

```output
Имя скрипта: ./args.sh
Первый аргумент: лаба3
Второй аргумент: срочно
Всего аргументов: 2
Все аргументы: лаба3 срочно
```

## Ввод от пользователя

```bash
#!/bin/bash
read -p "Как тебя зовут? " name
read -p "Номер лабы: " lab
echo "$name, создаю папку для лабы $lab"
mkdir -p "lab$lab"
```

`read -s` скрывает ввод — для паролей.

## Код завершения

Каждая команда возвращает **код завершения**: `0` — успех, другое число — ошибка. Последний код хранится в `$?`:

```bash
ls /nonexistent
echo $?          # 2 — ошибка

ls ~
echo $?          # 0 — успех
```

Скрипт может сам вернуть код через `exit`:

```bash
if [ $# -eq 0 ]; then
    echo "Укажите имя файла"
    exit 1
fi
```

## Цепочки команд

```bash
mkdir build && cd build        # вторая — только если первая успешна
cd project || exit 1           # вторая — только если первая не удалась
make; echo "готово"            # обе подряд в любом случае
```

## Строгий режим

В начало серьёзных скриптов добавляют:

```bash
#!/bin/bash
set -euo pipefail
```

| Опция | Что делает |
|---|---|
| `-e` | остановиться при первой ошибке |
| `-u` | ошибка при обращении к незаданной переменной |
| `-o pipefail` | конвейер считается неуспешным, если упала любая его часть |

> [!WARNING]
> Скрипт, созданный в Windows, может содержать окончания строк `\r\n`. Тогда bash выдаёт ошибку `/bin/bash^M: bad interpreter`. Исправить: `sed -i 's/\r$//' script.sh` или сохранить файл с окончаниями LF.
