# Текстовые редакторы: nano и vim

На сервере или в терминале без графики файлы правят консольными редакторами. Самые распространённые — `nano` (простой) и `vim` (мощный, но непривычный).

## nano

```bash
nano notes.txt          # открыть или создать файл
nano +15 main.c         # открыть на строке 15
```

Подсказки по клавишам видны внизу экрана. Символ `^` означает `Ctrl`, `M-` — `Alt`.

| Клавиши | Действие |
|---|---|
| `Ctrl+O`, затем `Enter` | сохранить |
| `Ctrl+X` | выйти (спросит про сохранение) |
| `Ctrl+W` | поиск |
| `Ctrl+\` | поиск и замена |
| `Ctrl+K` | вырезать строку |
| `Ctrl+U` | вставить |
| `Ctrl+_` | перейти к строке |
| `Alt+U` | отменить |

## vim

`vim` работает в **режимах** — это главное, что нужно понять:

| Режим | Как войти | Для чего |
|---|---|---|
| нормальный | `Esc` | перемещение и команды |
| вставка | `i` | набор текста |
| командный | `:` из нормального | сохранение, выход, замена |

```bash
vim main.py
```

Минимальный сценарий: `i` → набрать текст → `Esc` → `:wq` → `Enter`.

## Как выйти из vim

| Команда | Действие |
|---|---|
| `:w` | сохранить |
| `:q` | выйти |
| `:wq` или `:x` | сохранить и выйти |
| `:q!` | выйти **без** сохранения |

> [!NOTE]
> Если vim не реагирует на команды — вы, скорее всего, в режиме вставки. Нажмите `Esc` и повторите.

## Команды нормального режима

| Клавиши | Действие |
|---|---|
| `h j k l` | влево, вниз, вверх, вправо (стрелки тоже работают) |
| `gg` / `G` | в начало / в конец файла |
| `0` / `$` | в начало / в конец строки |
| `dd` | удалить (вырезать) строку |
| `yy` | скопировать строку |
| `p` | вставить после курсора |
| `u` | отменить |
| `Ctrl+r` | повторить |
| `/текст` | поиск, `n` — следующее совпадение |
| `o` | новая строка ниже и режим вставки |

## Замена

```text
:%s/старое/новое/g
```

`%` — во всём файле, `g` — все вхождения в строке. Добавьте `c` в конце (`/gc`), чтобы подтверждать каждую замену.

## Полезные настройки

Файл `~/.vimrc`:

```text
set number
syntax on
set tabstop=4
set shiftwidth=4
set expandtab
```

## Какой выбрать

- быстро поправить конфиг — `nano`;
- много работать на серверах — стоит освоить базу `vim`: он есть почти везде;
- для обычной разработки удобнее VS Code или IDE.

Редактор по умолчанию (например, для `git commit`) задаётся переменной `EDITOR`:

```bash
export EDITOR=nano
```

## Проверь себя

> [!QUIZ]
> Как выйти из vim без сохранения?
> ---
> `Esc`, затем `:q!` и `Enter`.

> [!QUIZ]
> Как сохранить файл в nano?
> ---
> `Ctrl+O`, затем `Enter`. Выход — `Ctrl+X`.
