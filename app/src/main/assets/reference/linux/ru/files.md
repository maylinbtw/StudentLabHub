# Работа с файлами и папками

Создание, копирование, перемещение, удаление и просмотр файлов — то, что приходится делать в терминале постоянно.

## Создание

```bash
touch notes.txt              # пустой файл (или обновить дату существующего)
mkdir lab3                   # папка
mkdir -p labs/2026/lab3      # вложенные папки сразу, без ошибок если уже есть
```

## Копирование: cp

```bash
cp main.c main_backup.c      # копия файла
cp main.c ~/backup/          # копия в другую папку
cp -r lab1 lab1_copy         # копия папки целиком (-r — рекурсивно)
cp -i *.c src/               # спросить, прежде чем перезаписать
```

## Перемещение и переименование: mv

`mv` и перемещает, и переименовывает — это одна и та же операция:

```bash
mv old.txt new.txt           # переименовать
mv report.odt ~/Documents/   # переместить
mv *.png images/             # переместить все png-файлы
```

## Удаление: rm и rmdir

```bash
rm temp.txt                  # удалить файл
rm -i *.log                  # спрашивать подтверждение для каждого
rmdir empty_dir              # удалить пустую папку
rm -r old_lab                # удалить папку со всем содержимым
```

> [!WARNING]
> В терминале нет корзины: `rm` удаляет навсегда. Особенно осторожно с `rm -rf` — он не задаёт вопросов. Перед удалением по маске проверьте, что попадёт под неё: `ls *.log`.

## Маски имён

Оболочка подставляет вместо масок подходящие имена файлов:

| Маска | Совпадает с |
|---|---|
| `*` | любым количеством любых символов |
| `?` | ровно одним любым символом |
| `[abc]` | одним из перечисленных символов |
| `{a,b}` | каждым вариантом по очереди |

```bash
ls *.c                       # все файлы с расширением .c
ls lab?.txt                  # lab1.txt, lab2.txt, но не lab10.txt
cp report.{odt,pdf} ~/send/  # то же, что cp report.odt report.pdf ~/send/
```

## Просмотр содержимого

```bash
cat notes.txt                # вывести файл целиком
cat -n main.c                # с номерами строк
less /var/log/syslog         # постраничный просмотр
head -n 20 data.csv          # первые 20 строк
tail -n 5 data.csv           # последние 5 строк
tail -f app.log              # следить за файлом в реальном времени
```

Управление в `less`: пробел — страница вниз, `b` — вверх, `/текст` — поиск, `n` — следующее совпадение, `q` — выход.

## Поиск файлов: find

```bash
find . -name "*.java"              # все .java в текущей папке и глубже
find ~ -iname "отчёт*"             # без учёта регистра
find . -type d -name build         # только папки с именем build
find . -size +10M                  # файлы больше 10 МБ
find . -mtime -1                   # изменённые за последние сутки
find . -name "*.tmp" -delete       # найти и удалить
```

## Ссылки

```bash
ln -s /opt/idea/bin/idea.sh ~/idea     # символическая ссылка (ярлык)
ls -l ~/idea
```

```output
lrwxrwxrwx 1 student student 22 окт 27 12:00 /home/student/idea -> /opt/idea/bin/idea.sh
```

## Архивы

```bash
tar -czf lab3.tar.gz lab3/         # упаковать папку в архив .tar.gz
tar -xzf lab3.tar.gz               # распаковать
zip -r lab3.zip lab3/              # zip-архив
unzip lab3.zip                     # распаковать zip
```

Буквы в `tar`: `c` — создать, `x` — распаковать, `z` — сжатие gzip, `f` — имя файла архива, `v` — показывать процесс.

## Проверь себя

> [!QUIZ]
> Как удалить папку вместе с содержимым?
> ---
> `rm -r папка`. Корзины нет — удаление окончательное.

> [!QUIZ]
> Как распаковать `lab3.tar.gz`?
> ---
> `tar -xzf lab3.tar.gz`.
