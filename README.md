# StudentLabHub

Android-приложение для студента: все лабораторные и практические работы, сроки сдачи и оценки в одном месте. Задания подтягиваются из Google Classroom автоматически.

**[⬇ Скачать APK](https://github.com/maylinbtw/StudentLabHub/releases/latest)** · Android 8.0+ · русский / English / беларуская

---

## Возможности

**Google Classroom**
- Вход через Google-аккаунт.
- Курсы Classroom сами становятся предметами, а задания — лабораторными (ЛР) и практическими (ПР) работами. Номер и тип работы распознаются по названию задания.
- Сроки сдачи, статус «сдано» и оценки подтягиваются из Classroom.
- Работы, возвращённые на доработку, помечаются отдельно.
- Синхронизация в фоне примерно раз в 6 часов. Обновить вручную можно, потянув экран вниз.

**Сегодня**
- Сводка: сколько работ просрочено, сколько сдавать сегодня и на этой неделе.
- Список дедлайнов по группам: на доработку, просрочено, сегодня, завтра, на этой неделе, позже.
- Календарь месяца: ближайшие дедлайны выделены красным, по нажатию на день показываются его работы.

**Расписание пар**
- Расписание группы подтягивается с сайта колледжа автоматически, несколько раз в день. Можно выбрать подгруппу.
- На «Сегодня» показываются ближайшие пары: время, предмет, аудитория, преподаватель, текущая пара подсвечена.
- Уведомление, когда выложили расписание на следующий день или оно изменилось.

**Очередь на защиту**
- Отметь работу «Нести на ближайшую пару» — она появится рядом с ближайшей парой этого предмета.
- Вечером накануне и утром приходит напоминание, что нести на защиту.

**Предметы и работы**
- Предметы по семестрам, добавление вручную, архив прошлых семестров.
- Статус работы меняется свайпом: не сделано → сделано → защищено.
- У каждой работы есть срок, оценка, заметки (например, вопросы преподавателя) и фото: отчёт, доска, задание.
- Статистика: средний балл по предметам и общий прогресс.

**Справочник**
- Статьи в формате учебника по Linux, C#, C++, Java и Python: главы, оглавление, примеры кода с копированием, вывод программ. Работает без интернета.
- Поиск по тексту статей с переходом к нужному разделу.
- Недостающую команду можно скачать из [tldr-pages](https://github.com/tldr-pages/tldr). После скачивания она доступна офлайн.
- Можно добавлять свои статьи.

**Удобство**
- Уведомления о дедлайнах за сутки и/или за 3 часа до срока.
- Виджет «Дедлайны» на рабочий стол и быстрые действия на иконке приложения.
- Тёмная (AMOLED или графит) и светлая тема, 8 акцентных цветов, крупный текст.
- Русский и английский язык с переключением в настройках.
- Резервная копия всех данных в файл и восстановление из него.

## Установка

1. Скачай `app-release.apk` со страницы [Releases](https://github.com/maylinbtw/StudentLabHub/releases/latest).
2. Открой файл на телефоне и разреши установку из этого источника.
3. Войди через Google.

> Приложение Google Cloud пока в тестовом режиме, поэтому войти через Google могут только аккаунты из списка тестовых пользователей. Чтобы тебя добавили, напиши автору.

## Технологии

| | |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3 |
| Архитектура | Clean Architecture + MVVM, ручное внедрение зависимостей |
| База данных | Room |
| Навигация | Navigation Compose |
| Сеть | Google Classroom REST API, Google Identity (AuthorizationClient) |
| Фоновые задачи | WorkManager |
| Расписание | разбор HTML-страницы расписания колледжа (windows-1251) |
| Виджет | Jetpack Glance |
| Минимальная версия | Android 8.0 (API 26) |

## Структура проекта

```
app/src/main/java/com/slh/studentlabhub/
├── data/           # Room, Classroom API, репозитории, резервная копия, справочник
├── domain/         # модели и интерфейсы репозиториев
├── di/             # AppContainer — сборка зависимостей
├── i18n/           # переключение языка
├── navigation/     # маршруты и нижняя навигация
├── notifications/  # напоминания и фоновая синхронизация
├── widget/         # виджет «Дедлайны»
└── ui/
    ├── components/ # общие компоненты (точечные цифры, свайпы, диалоги)
    ├── theme/      # цвета, шрифты, темы
    └── screens/    # today, subjects, lablist, labdetails, statistics,
                    # archive, reference, settings, auth
```

## Сборка из исходников

1. Клонируй репозиторий и открой его в Android Studio.
2. Для входа через Google нужен свой OAuth-клиент:
   - создай проект в [Google Cloud Console](https://console.cloud.google.com/) и включи **Google Classroom API**;
   - настрой экран согласия OAuth и добавь себя в тестовые пользователи;
   - создай OAuth-клиент типа **Android** с пакетом `com.slh.studentlabhub` и SHA-1 своего ключа подписи. Узнать SHA-1 можно командой `gradlew signingReport`.
3. Запусти конфигурацию `app`.

Без настройки Google всё остальное работает: можно добавлять предметы вручную, пользоваться справочником и демо-данными.
