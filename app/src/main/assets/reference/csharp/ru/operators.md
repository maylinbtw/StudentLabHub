# Арифметические операции

Операции работают с **операндами** — числами, переменными или выражениями. Результат можно сразу вывести или сохранить в переменную.

## Основные операции

| Операция | Смысл | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | 9 |
| `-` | вычитание | `7 - 2` | 5 |
| `*` | умножение | `7 * 2` | 14 |
| `/` | деление | `7 / 2` | 3 |
| `%` | остаток от деления | `7 % 2` | 1 |

## Целочисленное деление

Если оба операнда целые, результат тоже целый — дробная часть **отбрасывается**:

```csharp
int a = 7, b = 2;
Console.WriteLine(a / b);          // 3
Console.WriteLine(a / (double)b);  // 3,5
Console.WriteLine(7.0 / 2);        // 3,5
```

> [!WARNING]
> Типичная ошибка: `double avg = sum / count;` при целых `sum` и `count` даёт целое значение, а потом оно лишь превращается в `double`. Приведите один операнд: `(double)sum / count`.

Деление целого числа на ноль выбрасывает `DivideByZeroException`. Деление `double` на ноль ошибки не даёт: результат — `∞` (`double.PositiveInfinity`) или `NaN` для `0.0 / 0`.

## Остаток от деления

`%` часто используют для проверки чётности и кратности:

```csharp
int n = 15;
Console.WriteLine(n % 2 == 0 ? "чётное" : "нечётное");
Console.WriteLine(n % 5 == 0);    // True — делится на 5
Console.WriteLine(-7 % 3);        // -1: знак берётся от левого операнда
```

## Инкремент и декремент

`++` увеличивает переменную на 1, `--` уменьшает. Важно, где стоит оператор:

- **префиксная** форма `++x` — сначала меняет значение, затем возвращает новое;
- **постфиксная** форма `x++` — возвращает старое значение, затем меняет.

```csharp
int x = 5;
int y = ++x;   // x = 6, y = 6

int p = 5;
int q = p++;   // q = 5, p = 6

Console.WriteLine($"x={x} y={y} p={p} q={q}");
```

```output
x=6 y=6 p=6 q=5
```

## Составное присваивание

Короткая запись для «изменить переменную на значение»:

| Запись | Равносильно |
|---|---|
| `a += 5` | `a = a + 5` |
| `a -= 5` | `a = a - 5` |
| `a *= 5` | `a = a * 5` |
| `a /= 5` | `a = a / 5` |
| `a %= 5` | `a = a % 5` |

```csharp
int score = 10;
score += 5;   // 15
score *= 2;   // 30
```

`+=` работает и со строками: `text += "!"` дописывает символ в конец.

## Приоритет операций

Выражение вычисляется по приоритетам, а операции одного уровня — слева направо:

1. `x++`, `x--` (постфиксные)
2. `++x`, `--x`, унарный `-`
3. `*`, `/`, `%`
4. `+`, `-`
5. `=`, `+=`, `-=` и другие присваивания (справа налево)

```csharp
int r1 = 2 + 3 * 4;      // 14
int r2 = (2 + 3) * 4;    // 20
int r3 = 10 - 4 - 3;     // 3: (10 - 4) - 3
```

Скобки всегда меняют порядок и делают код понятнее — не экономьте на них.

## Класс Math

Для остальных вычислений есть статический класс `Math`:

```csharp
Console.WriteLine(Math.Pow(2, 10));      // 1024 — степень
Console.WriteLine(Math.Sqrt(81));        // 9 — квадратный корень
Console.WriteLine(Math.Abs(-7));         // 7 — модуль
Console.WriteLine(Math.Round(2.567, 2)); // 2,57 — округление
Console.WriteLine(Math.Max(3, 8));       // 8
Console.WriteLine(Math.PI);              // 3,141592653589793
```

> `Math.Round` по умолчанию использует «банковское» округление: `Math.Round(2.5)` даёт 2, а `Math.Round(3.5)` — 4. Для привычного округления передайте `MidpointRounding.AwayFromZero`.
