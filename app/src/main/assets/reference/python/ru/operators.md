# Операции

## Арифметика

| Операция | Пример | Результат |
|---|---|---|
| `+` `-` `*` | `7 * 2` | 14 |
| `/` | `7 / 2` | 3.5 — всегда дробный результат |
| `//` | `7 // 2` | 3 — целочисленное деление (вниз) |
| `%` | `7 % 2` | 1 — остаток |
| `**` | `2 ** 10` | 1024 — степень |

```python
print(-7 // 2)     # -4 — округление вниз, а не к нулю
print(-7 % 3)      # 2 — знак остатка как у делителя
print(divmod(17, 5))   # (3, 2) — частное и остаток сразу
```

> В отличие от C++, Java и C#, `/` в Python всегда даёт `float`: `6 / 2` равно `3.0`. Для целого результата используйте `//`.

## Составное присваивание

```python
x = 10
x += 5     # 15
x -= 3     # 12
x *= 2     # 24
x //= 5    # 4
x **= 2    # 16
```

Операций `++` и `--` в Python нет: пишите `x += 1`.

## Сравнение

```python
mark = 8
print(mark >= 7)            # True
print(4 <= mark <= 10)      # True — сравнения можно соединять в цепочку
print("abc" < "abd")        # True — строки сравниваются посимвольно
print([1, 2] == [1, 2])     # True — сравнение содержимого
```

`is` проверяет, один ли это объект, а не равенство значений. Используйте его только для `None`: `if value is None:`.

## Логические операции

В Python логические операции записываются словами:

| Операция | Пример |
|---|---|
| `and` | `mark >= 4 and not absent` |
| `or` | `weekend or holiday` |
| `not` | `not passed` |

```python
age = 19
has_pass = True
print(age >= 18 and has_pass)    # True
```

## Истинность значений

В условиях любое значение превращается в `bool`. Ложными считаются `0`, `0.0`, `""`, `[]`, `{}`, `None`, всё остальное — истинно:

```python
labs = []
if not labs:
    print("Список работ пуст")

name = input("Имя: ")
if name:
    print("Имя введено")
```

`and` и `or` возвращают один из операндов, а не обязательно `True`/`False`. Это используют для значений по умолчанию:

```python
group = input("Группа: ") or "ПЗТ-44"
```

## Математика: math

```python
import math

math.sqrt(81)        # 9.0
math.pi              # 3.141592653589793
math.ceil(2.1)       # 3
math.floor(2.9)      # 2
round(2.567, 2)      # 2.57
round(2.5)           # 2 — «банковское» округление к чётному
abs(-7)              # 7
max(3, 8, 5)         # 8
```
