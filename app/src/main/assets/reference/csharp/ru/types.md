# Типы данных

C# — язык со **строгой статической типизацией**: у каждой переменной есть тип, известный при компиляции. Тип определяет, какие значения можно хранить, сколько памяти они занимают и какие операции допустимы.

## Целые числа

| Тип | Размер | Диапазон |
|---|---|---|
| `byte` | 1 байт | 0 … 255 |
| `sbyte` | 1 байт | −128 … 127 |
| `short` | 2 байта | −32 768 … 32 767 |
| `ushort` | 2 байта | 0 … 65 535 |
| `int` | 4 байта | около ±2,1 млрд |
| `uint` | 4 байта | 0 … около 4,3 млрд |
| `long` | 8 байт | около ±9,2·10¹⁸ |
| `ulong` | 8 байт | 0 … около 1,8·10¹⁹ |

В большинстве случаев используют `int`, для очень больших значений — `long`. Точные границы хранятся в константах `int.MinValue`, `int.MaxValue` и т. п.

```csharp
int students = 28;
long population = 9_200_000_000; // _ разделяет разряды для читаемости
byte level = 255;

Console.WriteLine(int.MaxValue);
```

```output
2147483647
```

## Дробные числа

| Тип | Размер | Точность | Суффикс |
|---|---|---|---|
| `float` | 4 байта | ~6–9 цифр | `f` |
| `double` | 8 байт | ~15–17 цифр | — (или `d`) |
| `decimal` | 16 байт | 28–29 цифр | `m` |

Дробный литерал без суффикса имеет тип `double`. Для других типов суффикс обязателен:

```csharp
double distance = 12.5;
float speed = 3.6f;
decimal price = 199.99m; // деньги храните в decimal
```

> `double` хранит числа в двоичном виде, поэтому `0.1 + 0.2` даёт `0.30000000000000004`. Для денежных расчётов используйте `decimal` — он считает в десятичной системе без таких погрешностей.

## Логический тип

`bool` принимает только два значения: `true` и `false`. Его возвращают сравнения и используют условия:

```csharp
bool isPassed = true;
bool isAdult = age >= 18;
```

В отличие от C++, `bool` нельзя заменить числом: `if (1)` в C# — ошибка.

## Символы и строки

`char` — один символ Юникода в одинарных кавычках. `string` — последовательность символов в двойных кавычках:

```csharp
char grade = 'A';
string group = "ПЗТ-44";
string path = @"C:\Projects\Lab1"; // @ — обратная косая черта не экранирует
string empty = "";
```

Специальные символы записываются через `\`: `\n` — перевод строки, `\t` — табуляция, `\"` — кавычка, `\\` — сама косая черта.

## Тип object

`object` — базовый тип для всех остальных. В переменную `object` можно положить что угодно, но чтобы работать со значением, его придётся привести обратно к нужному типу:

```csharp
object value = 42;
int number = (int)value;
```

## Значимые и ссылочные типы

| Значимые типы | Ссылочные типы |
|---|---|
| `int`, `double`, `bool`, `char`, `decimal`, структуры, перечисления | `string`, `object`, массивы, классы |
| переменная хранит само значение | переменная хранит ссылку на объект |
| при присваивании значение копируется | при присваивании копируется ссылка |

Подробнее разница пригодится в главе про классы. Пока достаточно помнить, что `int` копируется целиком, а массив — по ссылке.

## Значения по умолчанию

Если поле класса не инициализировано, оно получает значение по умолчанию: `0` для чисел, `false` для `bool`, `'\0'` для `char` и `null` для ссылочных типов. Узнать его можно через `default`:

```csharp
Console.WriteLine(default(int));    // 0
Console.WriteLine(default(bool));   // False
```

## Nullable-типы

Значимый тип не может быть `null`. Чтобы разрешить «отсутствие значения», к типу добавляют `?`:

```csharp
int? mark = null;   // оценки пока нет
mark = 5;

if (mark.HasValue)
{
    Console.WriteLine(mark.Value);
}
```

У ссылочных типов знак `?` (например, `string?`) говорит компилятору, что `null` здесь ожидаем, и он перестаёт выдавать предупреждение.

## Проверь себя

> [!QUIZ]
> Какой тип выбрать для денежных сумм?
> ---
> `decimal`: он хранит десятичные дроби точно, без ошибок округления, как у `double`.

> [!QUIZ]
> Чем значимые типы отличаются от ссылочных?
> ---
> Значимые (`int`, `double`, `struct`) хранят само значение и копируются целиком. Ссылочные (`string`, массивы, классы) хранят ссылку на объект.
