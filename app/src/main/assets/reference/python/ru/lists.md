# Списки

**Список** (`list`) — упорядоченная изменяемая коллекция. Может хранить значения разных типов, но обычно в нём однотипные данные.

## Создание и доступ

```python
marks = [7, 9, 4, 8]
empty = []
letters = list("abc")        # ['a', 'b', 'c']
zeros = [0] * 5              # [0, 0, 0, 0, 0]

print(marks[0])              # 7
print(marks[-1])             # 8 — последний
print(len(marks))            # 4
marks[2] = 10
```

> [!WARNING]
> Индекс за пределами списка вызывает `IndexError`. Допустимые индексы: от `0` до `len - 1` и от `-len` до `-1`.

## Срезы

`список[начало:конец:шаг]` — конец не включается:

```python
nums = [0, 1, 2, 3, 4, 5, 6]

nums[1:4]     # [1, 2, 3]
nums[:3]      # [0, 1, 2]
nums[4:]      # [4, 5, 6]
nums[::2]     # [0, 2, 4, 6]
nums[::-1]    # [6, 5, 4, 3, 2, 1, 0] — разворот
nums[:]       # копия списка
```

## Изменение

```python
subjects = ["Математика", "Физика"]

subjects.append("Химия")            # в конец
subjects.insert(0, "История")       # по индексу
subjects.extend(["ОАиП", "БД"])     # несколько сразу

subjects.remove("Физика")           # по значению (первое вхождение)
last = subjects.pop()               # убрать и вернуть последний: "БД"
first = subjects.pop(0)             # по индексу: "История"
del subjects[0]                     # удалить по индексу

print(subjects)                     # ['Химия', 'ОАиП']
```

## Поиск и проверки

```python
marks = [7, 9, 4, 9]

9 in marks             # True
marks.index(9)         # 1 — первое вхождение
marks.count(9)         # 2
min(marks), max(marks) # (4, 9)
sum(marks) / len(marks)# 7.25
```

## Сортировка

```python
marks = [7, 9, 4]

marks.sort()                 # меняет сам список: [4, 7, 9]
marks.sort(reverse=True)     # [9, 7, 4]
new = sorted(marks)          # возвращает новый, исходный не меняется

names = ["олег", "Анна", "ира"]
names.sort(key=str.lower)    # без учёта регистра
```

## Генераторы списков

Короткий способ построить список из другого:

```python
squares = [x * x for x in range(1, 6)]          # [1, 4, 9, 16, 25]
good = [m for m in marks if m >= 8]             # с условием
upper = [s.upper() for s in ["a", "b"]]         # ['A', 'B']
```

## Копирование

```python
a = [1, 2, 3]
b = a            # та же ссылка
b.append(4)
print(a)         # [1, 2, 3, 4] — изменился и a

c = a.copy()     # или a[:] или list(a)
c.append(5)
print(a)         # [1, 2, 3, 4] — a не изменился
```

## Вложенные списки

```python
table = [
    [1, 2, 3],
    [4, 5, 6]
]
print(table[1][2])   # 6

for row in table:
    print(*row)
```

> [!WARNING]
> `[[0] * 3] * 2` создаёт **две ссылки на одну строку**: изменение одной строки изменит обе. Правильно: `[[0] * 3 for _ in range(2)]`.

## Проверь себя

> [!QUIZ]
> Что вернёт `nums[::-1]`?
> ---
> Новый список в обратном порядке.

> [!QUIZ]
> Чем `lst.sort()` отличается от `sorted(lst)`?
> ---
> `sort()` меняет сам список и возвращает `None`, `sorted()` возвращает новый список.
