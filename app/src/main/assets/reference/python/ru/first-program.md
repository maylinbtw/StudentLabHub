# Первая программа на Python

**Python** — интерпретируемый язык с простым синтаксисом. Код не нужно компилировать: интерпретатор читает и выполняет его строка за строкой. На Python пишут скрипты, веб-серверы, анализ данных, машинное обучение и автоматизацию.

## Установка и проверка

Скачайте Python 3 с python.org (в Windows при установке отметьте **Add Python to PATH**). В Linux он обычно уже установлен.

```bash
python3 --version      # в Windows: python --version или py --version
```

```output
Python 3.12.3
```

## Интерактивный режим

Команда `python3` без аргументов открывает **REPL** — режим, где каждая строка выполняется сразу. Удобно, чтобы что-то быстро проверить:

```text
>>> 2 + 2
4
>>> "лаб" * 3
'лаблаблаб'
>>> exit()
```

## Программа в файле

Создайте файл `hello.py`:

```python
print("Hello, World!")
```

И запустите:

```bash
python3 hello.py
```

```output
Hello, World!
```

Никаких классов, `main` и точек с запятой — программа начинает выполняться с первой строки файла.

## Отступы вместо скобок

В Python блоки кода выделяются **отступами**, а не фигурными скобками. Строка с `:` открывает блок, а все строки блока сдвинуты на одинаковое число пробелов (принято 4):

```python
mark = 8

if mark >= 4:
    print("Зачтено")
    print("Можно идти домой")
print("Эта строка вне условия")
```

> [!WARNING]
> Смешивание табуляций и пробелов или неровные отступы вызывают ошибку `IndentationError`. Настройте редактор, чтобы Tab вставлял 4 пробела.

## Главный блок программы

В программах из нескольких файлов код запуска пишут так:

```python
def main():
    print("Старт программы")


if __name__ == "__main__":
    main()
```

Блок под `if __name__ == "__main__":` выполняется, только когда файл запущен напрямую, а не подключён через `import`.
