# Операции

Операции C++ похожи на операции других C-подобных языков, но есть особенности: целые числа неявно превращаются в `bool`, а переполнение не проверяется.

## Арифметика

| Операция | Пример | Результат |
|---|---|---|
| `+` `-` `*` | `7 * 2` | 14 |
| `/` | `7 / 2` | 3 — целочисленное деление |
| `/` | `7.0 / 2` | 3.5 |
| `%` | `7 % 2` | 1 — остаток, только для целых |

```cpp
int sum = 25, count = 4;
double bad = sum / count;                          // 6 — деление целых
double good = static_cast<double>(sum) / count;    // 6.25
```

> [!WARNING]
> Деление целого на ноль — **неопределённое поведение**: программа может упасть, а может выдать мусор. Проверяйте делитель заранее.

Остаток от дробных чисел считает функция `fmod` из `<cmath>`.

## Инкремент и присваивание

```cpp
int x = 5;
int a = x++;   // a = 5, x = 6 — постфиксная форма
int b = ++x;   // b = 7, x = 7 — префиксная форма

x += 3;        // x = x + 3
x *= 2;        // x = x * 2
x %= 5;        // x = x % 5
```

> Не изменяйте одну переменную дважды в одном выражении: `i = i++ + ++i;` — результат не определён стандартом.

## Сравнение и логика

| Операция | Смысл |
|---|---|
| `==` `!=` | равно, не равно |
| `<` `>` `<=` `>=` | больше, меньше |
| `&&` | И |
| `\|\|` | ИЛИ |
| `!` | НЕ |

```cpp
int mark = 8;
bool good = mark >= 7 && mark <= 10;     // true
bool retake = !(mark >= 4);              // false
```

`&&` и `||` вычисляют правую часть, только если она нужна для результата.

## Числа как логические значения

В C++ любое число можно использовать как условие: `0` — ложь, всё остальное — истина:

```cpp
int left = 3;
if (left)                    // то же, что if (left != 0)
    cout << "Ещё есть работы\n";

bool flag = 42;              // true
int n = true + true;         // 2
```

> [!WARNING]
> Классическая ошибка: `if (x = 5)` вместо `if (x == 5)`. Это присваивание, его результат 5 — «истина», и условие выполняется всегда. Компилятор с `-Wall` предупредит.

## Математика: cmath

```cpp
#include <cmath>

double p = pow(2, 10);       // 1024
double r = sqrt(81.0);       // 9
double m = fabs(-3.5);       // 3.5
double c = ceil(2.1);        // 3 — вверх
double f = floor(2.9);       // 2 — вниз
double rnd = round(2.5);     // 3 — к ближайшему, половина от нуля
```

`abs` для целых находится в `<cstdlib>`, `fabs` и `abs` для дробных — в `<cmath>`.

## Переполнение

```cpp
#include <climits>

int big = INT_MAX;           // 2147483647
big = big + 1;               // неопределённое поведение, на практике — отрицательное число
unsigned int u = 0;
u = u - 1;                   // 4294967295 — для unsigned переход по кругу определён
```

Если значения могут быть большими, берите `long long`.

## Приоритет (от высшего)

1. `x++`, `x--`, вызов функции `f()`, индекс `a[i]`
2. `++x`, `--x`, `!`, унарный `-`, приведение
3. `*`, `/`, `%`
4. `+`, `-`
5. `<<`, `>>`
6. `<`, `<=`, `>`, `>=`
7. `==`, `!=`
8. `&&`
9. `||`
10. `?:`, `=`, `+=` и другие присваивания

Из-за пункта 5 при выводе выражений со сравнением нужны скобки: `cout << (a < b);`.

## Проверь себя

> [!QUIZ]
> Чему равно `7 / 2` и `7.0 / 2` в C++?
> ---
> `3` и `3.5`: если оба операнда целые, деление целочисленное.

> [!QUIZ]
> Что происходит при переполнении `int`?
> ---
> Для знаковых типов это неопределённое поведение: результат непредсказуем. Для больших чисел берите `long long`.
