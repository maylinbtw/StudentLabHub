# Сравнение и логические операции

Операции сравнения и логические операции возвращают `bool` — `true` или `false`. На них строятся все условия и циклы.

## Операции сравнения

| Операция | Смысл | Пример | Результат |
|---|---|---|---|
| `==` | равно | `5 == 5` | True |
| `!=` | не равно | `5 != 3` | True |
| `<` | меньше | `2 < 7` | True |
| `>` | больше | `2 > 7` | False |
| `<=` | меньше или равно | `4 <= 4` | True |
| `>=` | больше или равно | `3 >= 9` | False |

```csharp
int mark = 7;
bool passed = mark >= 4;
Console.WriteLine(passed);
```

```output
True
```

> [!WARNING]
> Не путайте `=` (присваивание) и `==` (сравнение). В C# запись `if (mark = 5)` не скомпилируется, потому что результат присваивания — `int`, а не `bool`.

## Сравнение строк

Для строк `==` сравнивает содержимое, а не ссылки:

```csharp
string a = "ПЗТ-44";
string b = "пзт-44";

Console.WriteLine(a == b);                                              // False
Console.WriteLine(a.Equals(b, StringComparison.OrdinalIgnoreCase));    // True
```

Операции `<` и `>` для строк не определены — для сортировки используют `string.Compare(a, b)`.

## Логические операции

| Операция | Название | Результат `true`, когда… |
|---|---|---|
| `&&` | И | оба операнда `true` |
| `\|\|` | ИЛИ | хотя бы один `true` |
| `!` | НЕ | операнд `false` |
| `^` | исключающее ИЛИ | операнды разные |

```csharp
int age = 19;
bool hasPass = true;

bool canEnter = age >= 18 && hasPass;     // True
bool weekend = false, holiday = true;
bool dayOff = weekend || holiday;          // True
bool workDay = !dayOff;                    // False
```

## Сокращённое вычисление

`&&` и `||` не вычисляют правую часть, если результат уже ясен по левой. Это защищает от ошибок:

```csharp
string? name = null;

if (name != null && name.Length > 3)
{
    Console.WriteLine("Длинное имя");
}
```

Если `name` равно `null`, проверка `name.Length` не выполнится, и исключения не будет.

> Операции `&` и `|` с `bool` тоже работают как И/ИЛИ, но всегда вычисляют обе части. В условиях почти всегда нужны `&&` и `||`.

## Приоритет

От высшего к низшему: `!` → сравнения `<`, `>`, `<=`, `>=` → `==`, `!=` → `&&` → `||`. Поэтому `a || b && c` означает `a || (b && c)`. Если сомневаетесь — ставьте скобки:

```csharp
bool result = (age >= 18 && hasPass) || isTeacher;
```

## Проверка диапазона

Частая задача — проверить, что число лежит в промежутке:

```csharp
int score = 8;
bool good = score >= 7 && score <= 10;

// то же с сопоставлением по шаблону (C# 9+)
bool good2 = score is >= 7 and <= 10;
```

## Проверь себя

> [!QUIZ]
> Чем `&&` отличается от `&` для `bool`?
> ---
> `&&` не вычисляет правую часть, если левая уже `false` (сокращённое вычисление). `&` вычисляет обе части.

> [!QUIZ]
> Чему равно `!(true || false)`?
> ---
> `false`: `true || false` = `true`, а `!` его инвертирует.
