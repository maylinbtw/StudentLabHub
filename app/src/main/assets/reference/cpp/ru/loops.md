# Циклы

В C++ есть циклы `for`, `while`, `do…while` и цикл по диапазону `for (x : коллекция)`.

## for

```cpp
for (int i = 0; i < 5; i++)
{
    cout << i << ' ';
}
cout << '\n';
```

```output
0 1 2 3 4 
```

В заголовке три части через `;`: инициализация, условие продолжения, шаг. Любую часть можно опустить: `for (;;)` — бесконечный цикл.

## while и do…while

```cpp
int n = 1234, digits = 0;
while (n > 0)
{
    n /= 10;
    digits++;
}
cout << "Цифр: " << digits << '\n';     // 4
```

`do…while` выполняет тело хотя бы один раз — удобно для меню и проверки ввода:

```cpp
int choice;
do
{
    cout << "1 — новая работа, 2 — список, 0 — выход: ";
    cin >> choice;
} while (choice != 0);
```

## break и continue

```cpp
for (int i = 1; i <= 20; i++)
{
    if (i % 3 != 0) continue;   // пропустить не кратные трём
    if (i > 12) break;          // выйти из цикла
    cout << i << ' ';           // 3 6 9 12
}
```

## Цикл по диапазону (C++11)

Перебирает все элементы массива, `vector`, строки и других контейнеров:

```cpp
#include <vector>

vector<int> marks = {8, 6, 9, 7};
int sum = 0;
for (int m : marks)
{
    sum += m;
}
cout << "Среднее: " << static_cast<double>(sum) / marks.size() << '\n';
```

```output
Среднее: 7.5
```

Чтобы изменять элементы, нужна ссылка `&`:

```cpp
for (int& m : marks)
    m += 1;                 // каждая оценка +1

for (const auto& name : names)
    cout << name << '\n';   // const auto& — без копирования строк
```

## Вложенные циклы

```cpp
for (int row = 1; row <= 3; row++)
{
    for (int col = 1; col <= row; col++)
        cout << '*';
    cout << '\n';
}
```

```output
*
**
***
```

`break` выходит только из внутреннего цикла. Чтобы выйти из обоих, используют флаг или выносят циклы в функцию с `return`.

## Частые ошибки

- `for (int i = 0; i <= n; i++)` при обходе массива из `n` элементов — выход за границу на последнем шаге;
- `;` сразу после заголовка: `for (...);` — тело цикла пустое, а блок ниже выполнится один раз;
- сравнение `int` и `size()` даёт предупреждение о знаковости: используйте `size_t i` или цикл по диапазону.

## Проверь себя

> [!QUIZ]
> Что такое `for (;;)`?
> ---
> Бесконечный цикл: все три части заголовка опущены. Выход — через `break` или `return`.

> [!QUIZ]
> Как пройти по всем элементам `vector<int> v`, не используя индексы?
> ---
> Циклом по диапазону: `for (int x : v)`.
