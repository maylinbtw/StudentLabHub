# Первая программа на C++

**C++** — компилируемый язык: исходный код сначала переводится компилятором в исполняемый файл, и только потом запускается. На C++ пишут системные программы, игровые движки, драйверы и всё, где важна скорость.

## Код программы

Создайте файл `main.cpp`:

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

Разберём по строкам:

- `#include <iostream>` — подключает библиотеку ввода-вывода. Строки с `#` обрабатывает **препроцессор** до компиляции;
- `int main()` — главная функция, **точка входа**. Выполнение программы начинается с неё;
- фигурные скобки `{ }` — тело функции;
- `std::cout` — стандартный поток вывода (консоль), `<<` отправляет в него данные;
- `std::endl` — перевод строки;
- `return 0;` — программа завершилась успешно. Ненулевое значение означает ошибку.

## Компиляция и запуск

В Linux или в терминале MSYS2 на Windows:

```bash
g++ main.cpp -o hello
./hello
```

```output
Hello, World!
```

Полезные параметры компилятора:

```bash
g++ -std=c++20 -Wall -Wextra main.cpp -o hello   # стандарт C++20 и все предупреждения
g++ -g main.cpp -o hello                          # с отладочной информацией (для gdb)
g++ -O2 main.cpp -o hello                         # с оптимизацией
```

> В Visual Studio создайте проект «Консольное приложение» и нажмите **Ctrl+F5**. В Code::Blocks и CLion достаточно кнопки «Собрать и запустить».

## Как работает сборка

1. **Препроцессор** обрабатывает `#include` и другие директивы.
2. **Компилятор** переводит каждый `.cpp` в объектный файл с машинным кодом.
3. **Компоновщик** (линкер) собирает объектные файлы и библиотеки в исполняемый файл.

Поэтому ошибки бывают двух видов: ошибки компиляции (синтаксис, типы) и ошибки компоновки (`undefined reference` — функция объявлена, но не найдено её определение).

## using namespace std

Все стандартные имена находятся в пространстве имён `std`. Чтобы не писать `std::` каждый раз, в учебных программах часто добавляют:

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "Привет!" << endl;
    return 0;
}
```

> В больших проектах и заголовочных файлах `using namespace std;` не используют: оно может вызвать конфликты имён. Для лабораторных работ это допустимо.

## Частые ошибки новичков

- пропущена `;` в конце инструкции — компилятор укажет на **следующую** строку;
- `main` с большой буквы — компоновщик не найдёт точку входа;
- кириллица в консоли Windows выводится «кракозябрами» — добавьте в начало `main` строку `setlocale(LC_ALL, "Russian");` и подключите `<clocale>`.
