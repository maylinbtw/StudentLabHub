# Переменные окружения и настройка оболочки

**Переменные окружения** — пары «имя = значение», которые оболочка передаёт каждой запущенной программе. Через них программы узнают домашнюю папку, язык, путь поиска команд и т.п.

## Просмотр

```bash
echo $HOME          # /home/student
echo $USER          # student
echo $SHELL         # /bin/bash
printenv            # все переменные окружения
printenv PATH       # одна переменная
```

| Переменная | Значение |
|---|---|
| `HOME` | домашняя папка |
| `USER` | имя пользователя |
| `PATH` | папки, где ищутся команды |
| `PWD` | текущая папка |
| `LANG` | язык и кодировка |
| `EDITOR` | редактор по умолчанию |

## Создание переменных

```bash
NAME="Анна"               # переменная оболочки — только здесь
echo "Привет, $NAME"

export GROUP="П-21"       # переменная окружения — видна запущенным программам
python3 -c 'import os; print(os.environ["GROUP"])'   # П-21

MODE=debug ./app          # только для одного запуска
unset NAME                # удалить
```

> [!WARNING]
> Вокруг `=` не должно быть пробелов. `NAME = "Анна"` — оболочка попытается запустить команду `NAME`.

## PATH

Когда вы вводите `python3`, оболочка ищет файл `python3` в папках из `PATH` по порядку:

```bash
echo $PATH
```

```output
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

Добавить свою папку со скриптами:

```bash
mkdir -p ~/bin
export PATH="$HOME/bin:$PATH"
```

Теперь скрипты из `~/bin` запускаются по имени из любой папки.

## Где сохранить настройки: .bashrc

Всё, что задано командой в терминале, пропадает после его закрытия. Чтобы настройки применялись в каждом новом терминале, их пишут в `~/.bashrc`:

```bash
nano ~/.bashrc
```

Добавьте в конец:

```bash
export PATH="$HOME/bin:$PATH"
export EDITOR=nano
alias ll='ls -alF'
```

Применить без перезапуска терминала:

```bash
source ~/.bashrc
```

## alias — короткие имена команд

```bash
alias ll='ls -alF'
alias gs='git status'
alias update='sudo apt update && sudo apt upgrade -y'
alias ..='cd ..'

alias              # список всех alias
unalias gs         # удалить
```

## Приглашение командной строки

Вид приглашения задаёт переменная `PS1`:

```bash
PS1='\u@\h:\w\$ '
```

| Код | Значение |
|---|---|
| `\u` | имя пользователя |
| `\h` | имя компьютера |
| `\w` | текущая папка |
| `\t` | время |
| `\$` | `$` для пользователя, `#` для root |

## Файл .env в проектах

Многие проекты хранят настройки в файле `.env`:

```text
DB_HOST=localhost
DB_PORT=5432
API_KEY=секрет
```

> [!WARNING]
> Файл `.env` с паролями и ключами нельзя добавлять в git. Впишите его в `.gitignore`.
