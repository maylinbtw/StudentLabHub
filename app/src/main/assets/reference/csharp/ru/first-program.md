# Первая программа

Создадим консольное приложение, которое выводит приветствие. Ниже — два способа: через терминал и через Visual Studio.

## Создание проекта в терминале

Команда `dotnet new console` создаёт проект по шаблону консольного приложения. Параметр `-o` задаёт папку:

```bash
dotnet new console -o HelloApp
cd HelloApp
dotnet run
```

```output
Hello, World!
```

В папке появятся файлы:

- `HelloApp.csproj` — файл проекта: версия .NET, настройки сборки, подключённые пакеты;
- `Program.cs` — исходный код программы;
- `bin` и `obj` — служебные папки, создаются при сборке.

## Создание проекта в Visual Studio

1. «Создать проект» → шаблон **«Консольное приложение»** (C#).
2. Указать имя и папку, выбрать версию .NET.
3. Нажать **F5** (запуск с отладкой) или **Ctrl+F5** (без отладки, окно консоли не закроется сразу).

## Код программы

Откройте `Program.cs`. Шаблон содержит одну строку:

```csharp
Console.WriteLine("Hello, World!");
```

- `Console` — класс для работы с консолью;
- `WriteLine` — метод, который выводит текст и переводит строку;
- текст в двойных кавычках — строковый литерал;
- точка с запятой завершает инструкцию.

Изменим программу, чтобы она спрашивала имя:

```csharp
Console.Write("Как вас зовут? ");
string? name = Console.ReadLine();
Console.WriteLine($"Привет, {name}!");
```

```output
Как вас зовут? Анна
Привет, Анна!
```

`Write` выводит текст без перевода строки, `ReadLine` ждёт ввода и возвращает строку, а знак `$` перед кавычками позволяет подставлять значения в фигурных скобках.

## Метод Main

Код выше записан в стиле **инструкций верхнего уровня**: компилятор сам оборачивает его в метод `Main`. В старых проектах и учебниках программа выглядит так:

```csharp
using System;

namespace HelloApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Hello, World!");
        }
    }
}
```

Оба варианта делают одно и то же. `Main` — **точка входа**: с него начинается выполнение. Параметр `args` содержит аргументы командной строки.

> [!WARNING]
> Инструкции верхнего уровня появились в C# 9 (.NET 5). Если среда в колледже создаёт проект с `Main`, пишите код внутри фигурных скобок метода `Main`.

## Проверь себя

> [!QUIZ]
> Какой командой создать и запустить консольный проект из терминала?
> ---
> `dotnet new console -n MyApp`, затем в папке проекта `dotnet run`.

> [!QUIZ]
> Чем отличаются `Console.Write` и `Console.WriteLine`?
> ---
> `WriteLine` после текста переводит курсор на новую строку, `Write` — нет.
