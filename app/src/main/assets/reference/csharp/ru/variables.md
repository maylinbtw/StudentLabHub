# Переменные и константы

**Переменная** — именованная область памяти, в которой хранится значение определённого типа. Значение можно менять во время работы программы.

## Объявление

Сначала указывается тип, затем имя:

```csharp
string name;
int age;
```

Несколько переменных одного типа можно объявить через запятую:

```csharp
int x, y, z;
```

## Присваивание и инициализация

Оператор `=` записывает значение в переменную. Если сделать это сразу при объявлении, получится **инициализация**:

```csharp
string name = "Анна";
int age;
age = 19;          // присваивание
age = age + 1;     // новое значение — 20

Console.WriteLine($"{name}: {age}");
```

```output
Анна: 20
```

> [!WARNING]
> Локальную переменную нельзя читать, пока ей ничего не присвоено. Код `int n; Console.WriteLine(n);` не скомпилируется: ошибка CS0165.

## Правила для имён

- имя может содержать буквы, цифры и знак `_`;
- имя не может начинаться с цифры: `2count` — ошибка, `count2` — можно;
- нельзя использовать ключевые слова (`int`, `class`, `if`…). Если очень нужно, ставят `@`: `@class`;
- регистр важен: `age` и `Age` — разные переменные.

## Вывод типа: var

Ключевое слово `var` позволяет не писать тип — компилятор определит его по значению справа:

```csharp
var city = "Гродно";   // string
var count = 10;        // int
var price = 9.99;      // double
```

`var` не делает переменную «любого типа»: после объявления тип зафиксирован.

```csharp
var count = 10;
count = "десять"; // CS0029: нельзя преобразовать string в int
```

`var` требует инициализации: строка `var x;` — ошибка.

## Константы

Значение **константы** задаётся один раз и больше не меняется. Объявляется со словом `const`:

```csharp
const double Pi = 3.14159;
const int MaxStudents = 30;

double area = Pi * 2 * 2;
// Pi = 3; — ошибка CS0131: константе нельзя присвоить значение
```

Значение константы должно быть известно на этапе компиляции: число, строка, `bool` или выражение из других констант.

## Область видимости

Переменная существует от места объявления до конца блока `{ }`, в котором объявлена:

```csharp
int outer = 1;
{
    int inner = 2;
    Console.WriteLine(outer + inner); // 3
}
// Console.WriteLine(inner); — ошибка: inner здесь не видна
```
