# Кортежи и множества

## Кортеж (tuple)

**Кортеж** похож на список, но **неизменяем**: после создания элементы нельзя заменить, добавить или удалить.

```python
point = (3, 4)
student = ("Анна", "П-21", 8.4)
single = (5,)          # кортеж из одного элемента — нужна запятая
empty = ()

print(student[0])      # Анна
print(len(student))    # 3
# student[0] = "Ира"   — TypeError: кортеж неизменяем
```

## Распаковка

```python
name, group, avg = student
print(name, avg)       # Анна 8.4

a, b = 1, 2
a, b = b, a            # обмен значений
print(a, b)            # 2 1

first, *rest = [1, 2, 3, 4]
print(first, rest)     # 1 [2, 3, 4]
```

## Когда брать кортеж

- фиксированный набор связанных значений: координаты, запись «имя — балл»;
- возврат нескольких значений из функции;
- ключ словаря — список ключом быть не может, а кортеж может:

```python
schedule = {("Пн", 1): "Математика", ("Пн", 2): "Физика"}
print(schedule[("Пн", 2)])   # Физика
```

## Именованный кортеж

```python
from collections import namedtuple

Student = namedtuple("Student", ["name", "group", "avg"])
s = Student("Олег", "П-22", 7.5)
print(s.name, s.avg)   # Олег 7.5
```

## Множество (set)

**Множество** хранит только уникальные значения без порядка и очень быстро проверяет, есть ли элемент.

```python
groups = {"П-21", "П-22", "П-21"}
print(groups)            # {'П-21', 'П-22'} — повтор убран
print(len(groups))       # 2

groups.add("П-23")
groups.discard("П-99")   # удалить, если есть (без ошибки)
print("П-22" in groups)  # True

empty = set()            # {} — это пустой словарь, а не множество!
```

Убрать повторы из списка:

```python
marks = [7, 9, 7, 4, 9]
unique = set(marks)          # {9, 4, 7} — порядок не гарантирован
print(sorted(unique))        # [4, 7, 9]
```

## Операции над множествами

```python
a = {1, 2, 3}
b = {2, 3, 4}

a | b      # {1, 2, 3, 4} — объединение
a & b      # {2, 3} — пересечение
a - b      # {1} — разность
a ^ b      # {1, 4} — симметричная разность
a <= b     # False — является ли a подмножеством b
```

Пример: какие предметы есть у обеих групп:

```python
p21 = {"Математика", "ОАиП", "Физика"}
p22 = {"Математика", "БД", "Физика"}
print(p21 & p22)   # {'Математика', 'Физика'}
```

> [!WARNING]
> Элементы множества должны быть неизменяемыми: числа, строки, кортежи. Список внутрь множества положить нельзя — `TypeError: unhashable type: 'list'`.

## Сравнение коллекций

| | Список | Кортеж | Множество | Словарь |
|---|---|---|---|---|
| запись | `[1, 2]` | `(1, 2)` | `{1, 2}` | `{"a": 1}` |
| порядок | да | да | нет | порядок добавления |
| изменяемый | да | нет | да | да |
| повторы | да | да | нет | ключи уникальны |
| доступ | по индексу | по индексу | проверка `in` | по ключу |
