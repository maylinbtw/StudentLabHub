# Ввод и вывод

Для вывода в консоль используется функция `print`, для ввода — `input`.

## print

`print` выводит значения через пробел и в конце переводит строку:

```python
done, total = 7, 10
print("Сделано", done, "из", total)
print("Без перевода строки", end="")
print(" — продолжение")
print("a", "b", "c", sep=" | ")
```

```output
Сделано 7 из 10
Без перевода строки — продолжение
a | b | c
```

- `sep` — разделитель между значениями (по умолчанию пробел);
- `end` — что вывести в конце (по умолчанию `"\n"`).

## f-строки

Самый удобный способ подставить значения в текст — **f-строка**: буква `f` перед кавычками и выражения в фигурных скобках:

```python
name = "Анна"
avg = 7.4567

print(f"{name}: средний балл {avg:.2f}")
print(f"Осталось работ: {total - done}")
print(f"{done=}")                 # отладка: печатает done=7
```

```output
Анна: средний балл 7.46
Осталось работ: 3
done=7
```

## Форматы чисел

| Формат | Значение | Результат |
|---|---|---|
| `{x:.2f}` | 3.14159 | 3.14 |
| `{x:,}` | 1234567 | 1,234,567 |
| `{x:.1%}` | 0.256 | 25.6% |
| `{x:5}` | 42 | `   42` |
| `{x:<10}` | "ЛР1" | `ЛР1       ` |
| `{x:03}` | 7 | 007 |

## input

`input` выводит подсказку, ждёт ввода и **всегда возвращает строку**:

```python
name = input("Как вас зовут? ")
print(f"Привет, {name}!")
```

Числа нужно преобразовать явно:

```python
age = int(input("Возраст: "))
height = float(input("Рост в метрах: "))
print(f"Через год вам будет {age + 1}")
```

> [!WARNING]
> Если ввести не число, `int(...)` выбросит `ValueError` и программа остановится. Для надёжного ввода оборачивайте преобразование в `try`.

```python
while True:
    try:
        count = int(input("Количество работ: "))
        break
    except ValueError:
        print("Нужно целое число")
```

## Несколько значений в одной строке

```python
a, b = map(int, input("Два числа через пробел: ").split())
print(a + b)

marks = list(map(int, input("Оценки: ").split()))
print(sum(marks) / len(marks))
```

```output
Два числа через пробел: 3 4
7
Оценки: 8 6 9 7
7.5
```

`split()` делит строку по пробелам, `map(int, ...)` превращает каждую часть в число.

## Проверь себя

> [!QUIZ]
> Как вывести `x` с двумя знаками после точки?
> ---
> f-строкой: `print(f"{x:.2f}")`.

> [!QUIZ]
> Как прочитать два числа из одной строки ввода?
> ---
> `a, b = map(int, input().split())`.
