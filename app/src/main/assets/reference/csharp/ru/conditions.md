# Условная конструкция if

Конструкция `if` выполняет код только тогда, когда условие истинно. Условие — любое выражение типа `bool`.

## if

```csharp
int mark = 9;

if (mark >= 9)
{
    Console.WriteLine("Отлично!");
}
```

```output
Отлично!
```

Если в блоке одна инструкция, фигурные скобки можно опустить, но лучше их ставить всегда: так проще добавить вторую строку и не ошибиться.

## if … else

Ветка `else` выполняется, когда условие ложно:

```csharp
int mark = 3;

if (mark >= 4)
{
    Console.WriteLine("Зачтено");
}
else
{
    Console.WriteLine("Пересдача");
}
```

```output
Пересдача
```

## Цепочка else if

Когда вариантов больше двух, условия проверяются по очереди сверху вниз. Выполняется первая подходящая ветка, остальные пропускаются:

```csharp
int mark = 7;
string result;

if (mark >= 9)
    result = "отлично";
else if (mark >= 7)
    result = "хорошо";
else if (mark >= 4)
    result = "удовлетворительно";
else
    result = "неудовлетворительно";

Console.WriteLine(result);
```

```output
хорошо
```

> Порядок важен. Если поставить `mark >= 4` первым, оценка 9 тоже попадёт в «удовлетворительно».

## Вложенные условия

Внутри одной ветки может быть другой `if`:

```csharp
bool isDone = true;
bool isDefended = false;

if (isDone)
{
    if (isDefended)
        Console.WriteLine("Работа закрыта");
    else
        Console.WriteLine("Нужно защитить");
}
else
{
    Console.WriteLine("Нужно сделать");
}
```

Глубокая вложенность читается плохо. Часто её можно заменить на `&&` или ранний выход из метода.

## Тернарная операция

Операция `? :` — короткая запись `if … else`, которая возвращает значение:

```text
условие ? значение_если_true : значение_если_false
```

```csharp
int mark = 5;
string status = mark >= 4 ? "зачтено" : "незачтено";
Console.WriteLine($"Статус: {status}");
```

```output
Статус: зачтено
```

Оба значения должны быть одного типа (или приводиться к общему). Вкладывать тернарные операции друг в друга можно, но читать такой код тяжело.

## Операции с null

Для проверок на `null` есть короткие операции:

```csharp
string? group = null;

string shown = group ?? "не выбрана";   // если null — взять правую часть
int? length = group?.Length;            // если null — результат тоже null
group ??= "ПЗТ-44";                     // присвоить, только если null
```

## Частые ошибки

- точка с запятой после условия: `if (x > 0);` — блок после неё выполнится всегда;
- сравнение `double` через `==`: из-за погрешностей лучше проверять `Math.Abs(a - b) < 1e-9`;
- лишнее сравнение с `true`: вместо `if (isDone == true)` пишите `if (isDone)`.

## Проверь себя

> [!QUIZ]
> Что делает выражение `x > 0 ? "плюс" : "не плюс"`?
> ---
> Это тернарный оператор: возвращает первое значение, если условие истинно, иначе второе.

> [!QUIZ]
> Почему `if (x = 5)` не компилируется в C#?
> ---
> Условие должно быть `bool`, а `x = 5` — присваивание типа `int`. Для сравнения нужно `==`.
